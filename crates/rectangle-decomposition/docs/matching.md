## 1. 用最大同色区间表达像素

直接 leaves 入口和预校验 image 入口共用行桶路径。边长为 `s` 的叶子向 `s` 行和 `s` 列各写入一个区间，桶内按起点排序，随后合并相邻同色区间。合法输入满足 `Σs ≤ Σs² ≤ n²`，因此展开区间不会超出每方向 `n²` 个。

增量 builder 保存行列区间列表，完成时排序并进入同一 chord／分区后端。所有入口都保证送给提取器的区间有序、无重叠，且同色相邻区间已经合并。

对相邻两行的区间 `a`、`b`，记 `start = max(a.start, b.start)`、`end = min(a.end, b.end)`。它们产生水平 chord 的条件就是：

```text
a.value == b.value
start < end
a.start != b.start
a.end   != b.end
```

例如上行 `[0,3)`、下行 `[1,4)` 同色，交集 `[1,3)` 两端都是凹角。起点不同意味着交集左侧只有一行继续同色；另一行不能继续，否则区间就不是最大区间。终点同理。这省去了重新查询邻近像素的工作，竖直方向完全对称。

两方向共用 `emit_chords_for_boundary` 双指针扫描。较早结束的区间向前推进；终点相同时两边同时推进。随后用 `(value, order)` 排序，`order` 保存提取顺序，使同色候选的相对顺序确定。

**不能省略的条件：**最大化同色区间是端点判定正确的前提。若改变输入规范化逻辑，必须重新验证这一前提。

## 2. 在整数格点上建立冲突图

每个颜色组单独建图。只有一个方向有 chord 时，全部候选都可保留，直接跳过匹配。

两个方向都有候选时，把水平 chord 覆盖的内部整数格点写入编号网格。每列用一个 y 位图记录有效位置；竖直 chord 与该列位图取交，枚举置位即可得到全部冲突。交点按闭线段判断，必须包含 chord 端点。

每列的轮次编号（generation stamp）区分不同颜色组和调用。只有列标记属于本轮、对应 y 位已置位，格点编号才允许读取。因此无需清空整张编号网格，也无需另存逐格点标记；轮次编号回绕时清空列标记即可。未激活槽的初值可以为零。

CSR（Compressed Sparse Row）用两个连续数组保存邻接表：顶点 `h` 的邻居位于 `edges[offsets[h]..offsets[h+1]]`。这样遍历时无需为每个顶点单独分配容器。

生成冲突边时按竖直顶点依次输出，同一右顶点的边连续。由右度数的前缀和定位这些边段，再按 `(右度数, 右编号)` 稳定计数排序右顶点，依次散布到左 CSR，所得邻接表自然有序。单个颜色组的这一步为 `O(C + E + n)`，无需逐个邻接表做比较排序。

**必须保持：**边缓冲按右顶点连续分组；一个内部格点至多记录一条水平 chord；右度数不超过 `n−1`。

## 3. 用预热减少搜索，用 HKDW 保证最优

匹配先进行三项便宜的预热：优先匹配左侧度为 1 的顶点、按右度数顺序贪心匹配、尝试长度为 3 的增广路径。预热阶段同时构建转置 CSR，供后续反向遍历复用。这里的度 1 处理是一次预热扫描，不是完整的递归消除算法。

增广路径在未匹配边与匹配边之间交替，两端均未匹配；翻转路径上的配对，会使匹配大小增加 1。预热只决定从哪个初始匹配开始，精确结果仍由后续搜索完成。

HKDW 是 Hopcroft–Karp 的 Duff–Wiberg 变体。其依据见 [Duff、Kaya、Uçar 的说明，第 3.3.2 节](https://epubs.stfc.ac.uk/manifestation/5901)。本实现每轮执行：

1. 从全部未匹配竖直顶点反向 BFS，找到距未匹配水平顶点最近的层次。
2. 从最短层上的未匹配水平顶点出发，沿层次约束 DFS，得到极大的一组顶点不相交最短增广路径。
3. 从剩余未匹配水平顶点追加 DFS，寻找更多本轮不相交路径，不再限制为最短长度。

两段 DFS 共用本轮访问标记，成功或失败搜索访问过的左顶点都不再展开；下一轮清除标记。这样追加搜索不会把每轮工作放大成对每个根重复扫描全图。队列和 DFS 都使用显式固定数组，不依赖递归栈。

匹配结束后，重新从**未匹配水平顶点**计算 [独立集公式](algorithm.md) 所需的可达集。不能直接使用从右侧开始的反向 BFS 标记，二者的起点和用途不同。

## 4. 用切线位图驱动矩形扫描

选中的 chord 被写入水平、竖直切线位图，合并操作是 OR，因此不要求切线有序。

`build_runs_for_row` 在竖直切线处分割同色区间；`merge_sparse_runs` 用双指针比较上一行活跃矩形和本行 run。只有标签、横向范围完全一致，且没有水平切线阻挡，矩形才继续延伸。其余矩形结束或新建。

`ActiveRect::match_key` 把标签和横向端点打包为整数比较键；起始行不参与匹配。两套活跃矩形数组通过交换引用交替使用，避免逐行复制整块内联数组。

## 5. 保持实现简洁的边界

这些优化依赖本问题的稳定条件：整数坐标、固定边长、最大同色区间、同向 chord 不相交和明确的容量上界。更改任何前提时，应同时复核 [资源上界](scratch.md) 和 [复杂度推导](research.md)。

不要把“某种输入更快”写成普遍保证。工程改动用完整分解测量：收益明显且可复现时保留；难以区别于噪声时优先选择较简洁的实现。测量记录属于实验或提交说明，正文只保留现有结构的理由和不变量。
