# Sky Tracer realtime atmosphere

Source: local Sky Tracer repository, commit
`b66b16342afe38e788a5ece5371d3b3a67c5909a`, `crates/sky-realtime`.
Author: linlin. License: GPL-3.0-only; the complete license text is in Prime's
root `LICENSE` (`LICENSE_prime` in the distribution).

Prime adapts the four-wavelength physical medium, fitted wavelength transform and
coordinates, directional successive-scattering solver, exact upper-atmosphere
Rayleigh moments, path integration and SkyView charts from that version.
The Slang adaptation is under `shaders/model/atmosphere` and
`shaders/entry/atmosphere`. Physical input data are exported reproducibly into
`src/client/resources/prime/atmosphere`; the exporter retains the source checkout
unchanged. GPU regression fixtures are generated by the original WGSL solver.

Prime retains its own world-coordinate mapping, extraterrestrial sun scale,
terrain sun-shadow model, aerial-perspective caches, Vulkan resource ownership
and submission protocol. Source and target models both use f32 spectral
transport; normalized source storage uses f16 and SkyView stores log Rec.2020
in f32. The upstream method remains an approximation, not an exact spectral
reference solution.

Prime PT migration: the same inputs are stored in named Safetensors arrays,
with the unchanged default solver exposed as an offline asset tool.
Runtime interfaces use prepared chart constants, hardware texture filtering
and dependency-keyed caches.

The earlier `shaders/model/atmosphere`, `shaders/entry/atmosphere` and
`src/client/resources/prime/atmosphere` paths describe legacy Prime provenance.
Prime PT maintains the adapted Slang modules in
`crates/prime-vulkan/shaders/atmosphere` and the physical assets in
`crates/prime-vulkan/assets/atmosphere`.
