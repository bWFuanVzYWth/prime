Incorporated asset scope and processing
--------------------------------------

Source repository: https://github.com/Mojang/bedrock-samples
Source commit: 921fafb05c93abeae56c2f2868cd8f942bdbcc0f
Source version: 1.26.30.5, published 2026-06-16

Prime incorporates material images for the Java blocks and items atlases,
including conduit/bell/enchanting-book sprites, from this reference as
editable 8-bit RGBA PNG files in:
  crates/prime-minecraft/assets/vanilla_pbr/minecraft/

The complete Java sprite IDs, selected source paths, matching decisions and
incorporated planes are recorded in the adjacent manifest.json. Matching uses
existing Java RGB, including explicitly accepted fuzzy matches; the game's own
base color, alpha and tint remain the source of those channels.

The offline importer changes material containers to PNG, aligns source frames
to the Java sheet layout, resolves the source metalness/subsurface winner rule
before filtering, and converts authored normals to the internal format.
RGB MER sources receive a zero subsurface channel. Original source paths and
hashes, per-version RGB matching and generated baseline pixel/file hashes
are recorded in the adjacent manifest.json and source.lock.json. Committed PNGs
are the final editable assets; later art edits may differ from those baselines.
Missing auxiliary planes use the internal constant defaults.
No Bedrock base-color images, original TGA files, models, behaviors, scripts or
general resource-pack loader are incorporated in this asset scope.

The material images retain Mojang's copyright and upstream Minecraft EULA terms.
Their PNG representation does not relicense them as Prime-authored GPL assets.
