# 离线光传输契约

外部“离线渲染模式”由独立的 `OfflineRenderer` 实现。它和 `RealtimeRenderer` 平级组合
`TraceBackend`、场景、材质、光源与 Vulkan 提交工具，不共享 set 1、wavefront 状态、输出
图像、调度或顶层传输策略。

离线与实时共享[渲染核心数据 IR](渲染核心数据IR.md)的场景身份、材质、颜色、坐标、精度准入
和传输语义；本文件只冻结离线会话、调度与当前物理布局，不建立第二套数据规范。

## 会话与资源

`OfflineSession` 在进入时冻结世界、resident scene、相机姿态、天文、灯光、材质、相机介质、
canonical texture generation/catalog、纹理 revision、动态纹理列表、传输设置，以及进入前实时显示通道的 16-byte
自动曝光状态。世界或资源变化会退出；纵横比变化只重建投影与离线尺寸资源并从 0 样本
重新累积。离线预览不重新测光；最终曝光仍可实时调整，Reinhard-Gamut 显示变换使用内部固定参数，自动测光
自动曝光强度只在恢复实时渲染后影响新的测光目标。

实时与离线 pipeline/SBT 可同时驻留，但分辨率相关资源严格互斥。进入离线前等待已有 GPU
工作完成并销毁实时输出、重建历史、raw signal 和当前 144-byte×2 realtime path；退出时同步销毁
离线运行均值、显示资源、144-byte×1 路径记录和 112-byte×1 阶段暂存。共享场景、TLAS/BLAS、
canonical texture generation 与大气保留。
曝光复制采用两阶段切换：请求帧仍由实时渲染器提交复制，完成回调只标记快照 ready；后续
帧确认完成后才销毁实时尺寸资源并创建离线资源，录制中的命令不会引用已退休缓冲。

## Wavefront ABI 与调度

当前离线路径记录为单槽每像素 144 bytes。每像素另有 112 bytes 阶段暂存：Trace 写入
100 bytes 的表面状态，Light Select 在尾部写入 12 bytes 的 Area 选择结果。精确字段、offset
和 padding 只以 `shaders/abi.json` 生成合同为准，不在本文复制第二套易漂移布局。Direct 在
Scatter 修改路径和介质栈之前消费这些状态，不再持久化 deferred Area 请求。
表面暂存只省略下游确定不读取的 texture LOD；精确命中位置和包含完整 triangle id 的
`motionZFlags` 逐位保留。
当前两层介质的 RGB 消光与 IOR 均为 f32，并逐位跨 dispatch 保留；`throughput.w` 以 f32 保存
eta scale。这些是误差门禁建立前的保守 encoding，medium identity 必须与连续参数分离，未来
收窄按核心 IR 的 TIR、Beer-Lambert 与 RR 分布合同验收。路径继续携带精确源图元身份，普通续接与 Area 阴影
均从未偏移的物理命中点发射；
完整规则见 [GPU 几何追踪精度契约](GPU几何追踪精度契约.md)。另有两条单槽索引队列。
队列缓冲区依次存放每像素 112 bytes 阶段暂存、两条 16-byte indirect command 和两条
每像素 4-byte uint 索引数组；CPU indirect offset 与 Shader 索引地址必须从同一暂存尾部计算，
索引区必须位于全部 command 之后，不得与表面暂存重叠。
当前 4K backing 为 2,189,721,632 bytes，即约 2088.28 MiB，不创建实时
stable radiance、raw frame、PSR 或反射/透射双路图像。

调度固定为：

```text
camera-trace → light-select[0] → direct[0] → scatter[0]
    → (maximumBounces - 1) ×
      (bridge-trace → light-select → direct → scatter)
    → sample-resolve
```

camera-trace 追踪相机射线并初始化路径；后续 bridge-trace 只追踪已压缩的续接队列。
light-select 独占两级灯光树遍历，direct 在 Scatter 之前完成介质段、发光、太阳与 Area NEE，
scatter 只负责 OpenPBR 采样、RR 和续接压缩。每条阴影连接在同一轮 direct 内立即消费，因而
不需要跨散射保留起点介质。总调度数固定为 `4 × maximumBounces + 1`。sample-resolve 将本帧样本并入
running mean。running mean 使用 RGBA32F，alpha 与 RGB 使用同一样本数累计修正后的测光
亮度；当前离线显示使用冻结曝光，因此 alpha 仅保留测光统计语义，不驱动预览。

## 透明与介质

每个透明界面从紧凑 OpenPBR 反射+透射闭包随机选择一个事件，sample PDF 包含事件选择概率，
因此每像素始终只有一条离线路径。反射保留介质栈；透射按闭包结果入栈或出栈并传递 relative
eta；实体玻璃与水的颜色只由介质栈按实际段长应用 Beer-Lambert 吸收，玻璃表面不额外乘
滤色；TIR 只产生反射。粗糙透明参与完整双侧
sample/eval/PDF 与 NEE，平滑 delta 透明跳过 NEE。实现完全位于 `shaders/bsdf/compact`；
仓库中不保留可编译的 RoboCute 参考闭包。

Vanilla 染色玻璃以 alpha 0.4 固定标定体积吸收，当前 texel alpha `<= 0.5` 选择光滑界面、
`> 0.5` 选择粗糙界面。普通玻璃主体为无色光滑介质，alpha `> 0.5` 的边框改为不透明粗糙
漫反射表面。粗糙度优先读取 LabPBR，否则读取“默认粗糙度”设置；alpha 不缩放粗糙度。
“无缝玻璃”默认开启：普通玻璃边框按无色光滑主体处理，染色玻璃的粗糙分类被禁用；体积
颜色、alpha 0.4 吸收标定及介质栈行为均不改变。关闭后恢复纹理装饰分区。

NEE 阴影不求解透明界面的 Snell 折射。`lighting.transparent_nee_mode` 的默认
`straight_approximation`（“稳定滤光”）保持原始表面到光源的直线连接，并通过透明实体的
有向边界距离矩稳定累计该线段上的 RGB 光学厚度；起点介质不预乘远端光源距离，因此短介质段
不会从两个巨大浮点数相减得到。真正零厚度的薄壁界面按 1/16 米名义厚度累计。这是明确的
直线吸收近似，不是镜面折射链连接。

`unbiased_bsdf_only`（“路径采样”）在 alpha 测试后把首个透明界面视为遮挡，只累计起点到该
界面的已有介质 Beer 段。透明折射链直接光因此只能由 BSDF continuation 命中，保持无偏但
可能极难收敛；无偏不表示有限采样下更接近预期画面。
实时与离线读取同一持久化枚举；Prime 不实现或暴露 MNEE。

## 直接光与 MIS

每个合格非 delta 顶点分别采一次太阳和一次两级灯光树 Area 光。若前一顶点存在 Area NEE
技术，BSDF 续接命中面积光时重建完整反向树 PDF 并使用 power heuristic；前一顶点为 delta
或没有该技术时权重为 1。太阳保持独立 NEE/MIS；行星地平线测试在太阳 shadow ray 前用
实际圆盘采样方向精确拒绝零贡献样本。产品默认最大反弹数为 16，可配置范围为 1–64；ABI 的
128 上限只作为内部安全容量。所有散射统一计入 bounce，并从
第二次散射开始 Russian roulette。透射事件把 `relativeEta²` 累积到 eta scale，存活率为
`min(sqrt(max(throughput) × etaScale), 1)`，存活路径按概率重加权。
灯光树的多条目终端叶使用 projected-solid-angle/接收法线朝向的近似目标，而不是静态功率；
该提议不替代 OpenPBR BSDF。正向叶选择与上述反向树 PDF 使用完全相同的 f32 归一化过程，
因此只改变方差，不改变估计量。

法线贴图表面的 evaluate、NEE 与 sample continuation 共用几何支持域：反射只接受几何法线
同侧，透射只接受异侧。无效 sample 终止路径，不重采样、不重新归一化、不做 Veach correction，
且不得先修改介质栈。面积发光纹理的 NEE 与 BSDF-hit 求值都固定读取 mip 0，从而使用相同
radiance 与 MIS 权重；可见表面抗锯齿不能通过只改变其中一种技术的发光 LOD 实现。
