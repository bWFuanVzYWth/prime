# 自定义表面编译

静态地形只有一条翻译路径：Java 绑定实际源字段，`prime_minecraft` 在生成几何前解决版本语义和接触关系，`prime_scene::surface` 完成版本无关裁切与合并，`prime_vulkan` 打包直接记录并使用硬件三角形求交。没有旧编译开关、逐帧编译配额或 GPU 模板解释链。源 ABI 见 [ABI](abi.md)，宿主兼容边界见[源路由](capture-boundaries.md)。

## 一次准备、放置与接触

模型资源在 epoch 内不可变。同向精确副本、等价正反面和已知 0.002/16 内壳在资源准备时生成配方；放置时按原剔除条件激活，不先展开全部光栅副本。几何与 UV 的原始 `012 / 230` 三角化都参与证明。相同四角位置不能单独证明不同对角线的插值等价：换对角只接受精确、非退化的平行四边形，且每个源面的 UV 都满足仿射关系；对角和与面积使用保留舍入残差的精确判断。非平面、非仿射 UV、未知重叠、真正薄壳和无法解释的层保留来源顺序，不做通用 epsilon 焊接。

原版 `cross` / `tinted_cross` 的正反面采用不同对角线。同一物理平面的两侧通过上述证明后生成一个 `Bilateral` 表面，按物理顶点对应保存各侧源 UV；两个相交平面仍独立。纹理、tint 与剔面条件分别保留，不能用统一的 `1-u` 推断背面 UV，也不能让重合的双面 quad 竞争最近命中。未满足证明的自定义模型继续保留原三角化。

确定性的 Multipart/Alias 根可一次合并子模板，跨子部件识别关系。包含 Weighted/未知子节点的根继续按源种子和重置顺序选择，不额外执行宿主 selector 或 emission 回调。草侧、红石覆盖和材质纠正留在 MC 适配 crate；generic 核心只认识已经证明的关系。

`SurfaceFace` 保存一份 quad 几何及可选的第二侧/层：`Bilateral` 按入射侧选材质，`OverlayFront` 仅在正面测试覆盖，`OverlayBoth` 在两侧测试。覆盖层未命中时使用基底。每层保留各自逐角 UV、颜色、纹理、coverage 和发光；有 opaque 基底的覆盖关系仍可走 AS opaque 路径。最近命中、阴影、空气透视遮挡和灯采样共用选侧/覆盖规则。

接触编译只访问自持的 section 和完整邻域。普通 opaque 面使用原有 SoA 剔面快路；仅因邻接普通 cutout 不进入接触生成，确定保留的 opaque 面不切开重组；无复合/光学属性的均匀色产物继续使用紧凑 CPU quad；流体、已识别光学材料、覆盖层和部分占据才进入接触处理。模板的闭合有向轴对齐面可证明占据体积；不能从名字、sturdy 或 raster face shape 推断实体体积。非平面水面按原两个三角面的高度分区，含水部件只移除实际占据的流体区域，干湿部分有不同介质端点。

Single、Local 与 Global palette 的状态行都包含同一份接触、光学与发光事实；压缩存储方式不改变水/玻璃边界、局部占据或岩浆发光。零位单状态段也进入与其他编码相同的表面解释路径。

局部交/差集先尝试矩形快路；非仿射或不同对角线按原三角形裁切，重心插值同时保持两层属性。已知流体侧面/底面 0.001 内缩只在有已知邻居时恢复；树叶间隙和未知偏移保留。斜面不会被吸附到近似平面。

一个接触 patch 只有一个拥有者：若只有一侧属于可发布的完整单元，归该侧；否则按世界 block 坐标字典序选择。完整单元集合的进入/退出使邻域消费者失效，不能因 halo 所属 section 暂时不可发布而丢面。状态边界比较包括模型、发光、光学/占据事实，编辑、资源重载和所有者变化使用同一发布路径。

## 矩形合并

严格整数网格 1×1 面使用同标签最优矩形分解；启用 OMM 时，完整 sprite、D4 UV 映射且 alpha=1 的镂空面改用 1/2/4 tile 方形，匹配预建的有限资源模板。裁切、斜向 UV 或不匹配 tint 保留原矩形分解，不为模板未命中的来源增加三角形，具体范围见 [OMM](opacity-micromaps.md)。新增部分矩形规则接受轴对齐、原两半具有同一仿射 UV 的面：至少一个几何方向长度恰好为 1，沿它自身的完整方向合并连续条带。不是固定全局轴，也不将所有部分面铺成稠密 1/16 网格。半砖侧面、活版门薄边、竖向栅栏窄面均由此规则覆盖；另一方向的区间必须一致。

方向、平面、64 块局部域、来源域、每侧/层材质、颜色、UV 周期/相位、coverage、介质及发光共同限定合并。孔洞、重叠或不兼容邻面中止条带。逐角渐变、非仿射关系和不满足单位方向条件的碎片保留。未知同格重叠的所有参与面都排除出合并。

`RepeatUv` 为两行 f32 仿射映射加轴掩码，只对合并方向执行 `frac`；窄边保留实际裁切区间和端点，不拉伸纹理，也不把半砖的半张纹理重复成整张。复合表面同时证明第二层映射。compiler scratch 随同步 Rust worker 复用，全部任务返回前 join。

所有产物统一 quad：一般 quad 保持原剖分；独立三角形 ABC 写成 ABCC，第四角复制完整属性。没有第二套常驻三角形格式或 primitive→quad 映射。封闭输入若证明完全不变可复用原共享页；显式关系产物不能仅凭“数量相同”判定不变。

## 直接 GPU 记录

| format | 步长 | 内容 |
| --- | ---: | --- |
| 0 | 176 B | 四个位置、四角完整 f32 颜色/UV、纹理/coverage |
| 1 | 240 B | 增加重复映射、发光、介质/emitter 身份和属性位 |
| 2 | 272 B | format 1 加正负两侧 IOR/消光系数 |
| 3 | 432 B | format 1 加第二层完整属性、映射、发光及可选光学端点 |

前 176 B 共用布局：位置 0–63，颜色 64–127，UV 128–159，纹理/coverage 160/164，关系模式 168。扩展的 176/192 为 UV 两行，208 为发光 RGB 与 `power/area`，224 为负/正介质、emitter、属性位。format 2 的端点在 240/256；format 3 的第二层颜色在 240、UV 在 304、纹理/coverage/属性在 336/340/344、重复映射在 352/368、发光在 384、端点在 400/416。端点为 `float4(ior, extinction)`。

每个 quad 固定两个 primitive 槽，共享索引 `012 / 230`；`primitiveIndex >> 1` 直接寻址，最低位选择半面。BLAS geometry、分配和上传范围保持完整 pair，局部指针范围采用 `floor(2^32/432)` 的保守记录上限。退化半面仍计入 AS 输入槽与尺寸查询，不能视为免费。

静态按实际字段拆成少量格式范围，一个单元仍一个 BLAS；局部复杂面不扩大普通面。对象原型与动态桶保持 176 B。静态 geometry 表项 64 B，携带记录地址/格式、规范灯页的首 emitter 身份、灯地址/格式和单元平移；入口零携带世界灯网格地址。一个源网格的所有材质格式范围共享同一规范灯页，命中时不能把可重排的 geometry 下标当作稳定灯身份。CPU 模板、MC 名称、源对象图不进入 GPU。

六种预建 specialization 组合为普通、仅重复映射、复合/纹理扩展、扩展有灯、光学无灯、光学有灯；共享接口，删去场景未使用的读取/NEE/折射分支。只有重复映射的场景不承担复合记录和 sprite 采样成本。首次出现灯或玻璃不临时编译管线。这增加初始化成本，是否保留以完整帧对照判断。

材质池每种格式从 4 MiB 起，后续页倍增至 64 MiB；超大连续请求单独满足。既有设备地址不迁移，不增加 shader 寻址层。材质、AS/scratch、上传池仍保留历史峰值和页预留；有效记录减少不等于等量显存回收。诊断和成本夹具分别报告记录、实际池容量、活跃 BLAS、构建/上传页和索引；活跃 BLAS 是构建池中的子分配，二者不能重复相加；累计 allocated bytes 不是当前常驻显存。

## 光学模型

标准水为 IOR 1.333、线性 Rec.2020 消光 `(0.2916, 0.04444, 0.010182)`；玻璃消光沿用旧项目白底透明色校准和 0.4 参考不透明度。参考色取源 sprite 首帧中心 texel，避免边框油漆污染透明主体；自定义裁切 UV 的局部消光参考尚未独立建立。缺 LabPBR 时玻璃 IOR 为1.5，有规范 G 时按清洗后的 dielectric F0 转为 IOR。均匀源在 CPU 建立介质身份；空间/动画变化的 G 保留源身份，当前表面负侧按命中 UV、邻接正侧按固定 sprite midpoint，分别读取当前帧 mip0 G。消光仍为 homogeneous 参考。引用使用已有光学记录与稳定 texture descriptor，不扩张几何步长。通道及支持边界见[材质契约](materials.md)。

玻璃必须来自实际玻璃类型标志、无未知 tint，并具有确定性的闭合轴对齐体积或共面薄片证明；复杂开放/随机模型保留源 coverage，计入 `hacks.optics`。同介质身份包括颜色族与光学参数；仅在两侧都是实体透射、无涂层/发光/tint 时消去相同介质边界，不因名字或平均颜色相同猜测。

实时与离线路径共同消费 Full OpenPBR opaque 与 solid/thin dielectric 的支持子域；sample/evaluate/PDF、Fresnel/TIR、Beer 吸收与 eta² 辐亮度权重保持同一生产核，LabPBR 法线和粗糙度进入相同消费。精确 Fresnel、transmission 能量补偿及厚壁 SSS 的单独 Lite 退路见[材质契约](materials.md)。首条射线从首个已知边界或介质中的 opaque 接触面确定入射介质；没有足够边界证明的复杂场景不保证初始介质正确。薄片用 1/16 m 有效厚度及双界面 Fresnel。NEE 的直线连接积累端点/路径长度、Fresnel 与薄片吸收，不解算折射焦散连接。foliage 底层接口已保留，MC 树叶未按旧 PBR preset 自动选择该拓扑。

未知 translucent 材料仍使用原 stochastic coverage；这与有证明的介质输运分别表示。大气阴影列存 opaque 深度，忽略透射边界，不存彩色透射；空气透视不在已知水/玻璃内重复叠加空气段。动态实例未接入光学介质，不能由静态夹具推断它已经支持。

## Sprite、动画与发光

Java 转录真实 sprite 身份、atlas bounds、帧尺寸、原始帧序列/时长/插值开关和各级 mip 像素。Rust 将已证明在 sprite 范围内的 atlas UV 转为 local UV，只修正端点外四个 ULP 内的误差；明显越界保留原 atlas UV 并计入 `hacks.sprite`，该兼容回退不承诺跨 sprite 动画和 mip。

静态基色 mip0 直接共享已捕获的 atlas Arc，动画使用自持完整帧图，各级基色 mip 保留原始像素。CPU/GPU 按实际共享像素分配计费；全部动画帧、mip 和规范辅助图都计入 512 MiB 源纹理预算，不按可见窗口低估，也不将 atlas 每个视图重复计费。64 B 纹理描述符保存偏移、尺寸、行步长、下一帧、mip 区间、独立材料视图和 atlas bounds；基色动画只改描述符，LabPBR 辅助动画按源规则在 CPU 混合后局部发布，不重建 BLAS。静态 atlas lookup 使 atlas UV 消费共享对应 sprite 的材料视图，不随动画重建整张材质 atlas。资源仍以 epoch 为寿命，尚无活跃 sprite 的细粒度驱逐。

26.2/26.3 的宿主 shader 对编码域 RGBA 四个通道插值并写入 UNORM8；Rust 按源 tick/时长生成相同的千分位进度，GPU 插值后按 UNORM8 舍入。着色按主像素射线锥估计 mip，层内最近点、层间线性；coverage 与灯支持域固定 mip0，因此不会随查询类型改变几何覆盖。射线锥不包含粗糙反弹的扩散，此过滤是明确的近似，不声称与光栅导数逐像素相同。动画按源帧传入的 game time 推进，离线冻结不更新。

有效 `format=lab-pbr/1.3` 包的 `_n/_s` 原图由 Java 读取，在 Rust 生成规范 mip 和辅助动画。连续通道层内/层间线性过滤；normal 分布保持 GGX 平均长度，specular 的分类 G/B 在生产固定当前帧 mip0 点样。非金属 authored SSS 中，optical thin 或 cutout SSS 使用 Full thin-material 的有色双半球反射/透射；其余 thick 分支单独保留历史 Lite 白色 diffuse transmission，介质身份不变。thick 分支是低阶近似，不执行体积 random walk；foliage 不套用旧树叶预设。AO/porosity 只保留，不直接乘着色；height 保留逐帧 min 解码，旧 voxel displacement 几何管线不移植。旧材质预设不参与默认值或分类。

游戏发光使用实际 block/quad emission 的较大值，按旧校准 `1.5 * (level/15)^2` 变为线性 BT.709 RGB，再乘采样点的解码纹理×tint。岩浆进入相同路径。光源从最终面提取，每个物理 patch 只计一次；复合面 proposal 覆盖两侧/层的功率上界，实际采样按选侧/coverage 计算发光，涂层挡住的底层不泄漏。

存在 authored LabPBR emission 时，上述宿主 ordinal emission 由 specular A 替换：0..254 解码 A/254，255 sentinel 为0；全 source sheet 所有帧 A 均为255时保留宿主来源。0明确关闭发光。CPU 使用全帧最大强度建立静态 proposal，shader 命中/NEE 使用当前实际采样强度；动画不改变 alias 支持域。满强度继续使用1.5校准，AO/porosity不额外降低发光。

生产默认使用单级局部网格 alias：世界对齐 cell 边长 16，局部球半径 24，非空格以 3/4 概率选择局部灯、1/4 概率选择全局功率灯。全局先选灯页再选页内灯，两个步骤使用独立样本；不上传或遍历旧功率树。局部成员取灯中心到 cell 中心的距离，权重为 `power / max(distance², 1 + 16²/4 + extent)`；矩形的 `extent=(|u|²+|v|²)/3`，一般 quad 的中心和 extent 按原两半采样面积权重计算质心及面积二阶中心矩，包含退化半面。该权重是提议近似，不改变真实发光、面积或可见性。无朝向裁剪、候选重采样或查询捷径。

每个局部灯页采用其实际需要的最大记录格式（240/272/432 B），普通灯不为第二层付费。按原 `012/230` 两半真实面积选择再重映射样本，零面积半面无采样质量。稳定灯身份查询独立的总面积倒数；前向面积 PDF 和发光命中反向 PDF 共同使用 `q = 1/4*qGlobal + 3/4*qLocal`，再除以该总面积。反向局部格来自上一未偏移着色点，不是命中灯或相机的位置。空格只用全局 PDF；覆盖失败产生零贡献，不重采。NEE/BSDF 使用 MIS，连续反射/透射使用其实际闭包 PDF；delta 事件不与连续 PDF 竞争。

局部表每项 16 B，保存稳定灯身份、alias、阈值和所表示的离散概率；独立灯引用 16 B，页内 alias 8 B，世界页 alias 16 B，灯页描述 48 B，稀疏格目录槽 32 B，世界头 64 B。目录只含至少一个局部成员的格子，不依赖当前相机或测试接收点。每个灯散射到半径内的格子，因此扩大视距的主要成本是局部引用复制，不是格头。稳定身份区分紧凑的 TLAS/geometry 页号，页增删只重建其影响的局部格；世界页概率变化不重建其他格。anchor 使用整数格坐标加余量，平移 anchor 不重建局部 alias。

表项、目录、全局页与场景同时发布。局部表使用可复用设备页中的独占分配，旧分配按 GPU 完成值退休；页目录与世界概率按发布版本一致，不能由帧数推测引用已失效。稳态和纯材质动画不建表。单表的 24-bit 格点概率校验与多维随机序列的收敛是不同契约，见[采样域](shaders.md#采样域)。

世界 alias、页描述、稀疏目录和世界头复用按需增长的设备 buffer，全部 staging 从已有上传池取得。旧 shader 读取先于新 transfer 写入，新表和范围统一发布后才允许消费；扩容旧 buffer 和 staging 仍按真实完成值退休。成员减少时按当前逻辑目录长度重新生成 hash mask，保留容量不扩大可寻址逻辑表。移除全部光源时释放该采样 owner；非空时仍保留容量峰值。

动画采用不依赖当前 texel 的固定 proposal，因此仅材质动画无需重建灯表；source emission 或几何变化仍重建对应静态簇及受影响的局部灯格。动态发光和纹理重要性 proposal 尚未注册。

## 发布与验证

源资源、几何、材质与灯在同一次有效发布中可见。全部边界验证在 mutation 前完成，失败不推进 scene revision/完成水位；待颜色/资源由 Rust 显式所有者持有。旧 CPU 快照按 Arc 生命周期、GPU 资源按实际完成或取消证明回收，不按经过帧数猜测。

源解释、自定义几何关系和 GPU 输运分别验证。未改语义的宿主夹具仍严格比较三角形多重集合；已声明修复按独立表面查询比较覆盖、两侧材料、局部 UV/颜色、占据和介质。重三角化会改变重心舍入和安全起点误差界，纹理边缘用像素误差界验收；同策略的增量/新建场景要求一致。

性能优先级为稳态帧数 > 显存节省 > 加载效率。原生 1920×1080、固定源/相机/种子/预算，分别记录稳态 CPU/GPU、实际预留、更新到完成 p95 和吞吐量。局部夹具不能外推实际跑图或完整资源包。临时数据在 artifacts，真实游戏由用户手动验收。复杂度显著增加而整帧收益有限的可选技巧应简化或移除，不为它保留第二套长期路径。
