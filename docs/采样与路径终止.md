# 采样与路径终止

实时以便于时间重建、维持有效深层照明为目标；离线比较同一积分模型在相同时间下的方差。
更高存活率或更高 active threads 不自动代表更好的性价比。

## 随机数域

实时使用共享的 `128×128×64×3` RG16UI STBN 表，连续二维样本由 16 位 rank 的中点
解码。方块灯、太阳、延续方向和首透明选枝使用分离的 bank / vertex / branch / epoch
地址；轻量首选枝占 vertex 0，灯光与延续分域覆盖配置允许的 64 轮。

灯光树及 alias 等离散选择不能只使用 16 位中点：小概率区间可能永远抽不到。离散
采样保留 STBN 的高 16 位顺序，用独立 hash 域填充低位，得到 [0,1) 的 24 位样本，
再按既有分支重映射。连续方向样本不因此全部改用白噪声。RR 使用独立 hash，离线
保持独立的 Sobol 采样域；不以“地址不同”直接证明统计独立。

## 线性俄罗斯轮盘赌

所有渲染器采用同一概率曲线：

```text
p = clamp(maxRGB(beta) × etaScale, 0, 1)
survive: beta = beta / p
```

beta 包含真实材质响应、首透明选枝补偿和介质吸收。透射的 `relativeEta²` 累积到
etaScale；轻量直通模型固定 etaScale=1。完整路径逐位保存 f32 etaScale，不能因
dispatch 分界量化它并改变存活分布。没有平方根、首反照率去调制补偿、额外概率地板
或相应调试开关。

当前顶点的 emission 和 NEE 在 RR 前结算，RR 只决定后继；存活路径必须除以实际 p，
不能只改变概率或重复补偿。零贡献、无效 BSDF、miss 和配置截断是独立的终止原因。

| 模式 | RR 起点与上限 |
| --- | --- |
| 完整实时 | 前置 delta 链无 RR；主体达到最小轮数后在 scatter 发布前执行，保留首个次级 guide 查询和待定透明 guide 阻塞规则 |
| 轻量实时 | 第 j 个 Lambert 面完成后，仅 M≤j<K 时执行；终点查询不再 RR |
| 离线 | 从第二次散射开始；所有散射计入配置的最大反弹数 |

实时共享设置 D/B 默认 12，M 默认 2，实际主体 K=max(M,B)。详细截断位置分别见
[完整实时调度](完整实时Wavefront调度.md)、[轻量路径追踪](轻量路径追踪.md)和
[离线光传输契约](离线光传输契约.md)。两种实时模型的最终端点处理并不相同。

## 首透明选枝与重建

完整实时首透明面先产生既有条件透射/反射候选，再对后续照明做 Bernoulli 稀疏化。
两候选有效时各取 1/2，所选 throughput 乘 2；单候选有效时概率与权重均为 1。
这不改变条件 PDF、MIS、首面已结算的 NEE/emission 或 guide albedo。

```text
E[P + 2 I_T T + 2 I_R R] = P + T + R
```

选枝补偿和 RR 的 `1/p` 是独立层次。两路 guide 始终补齐，照明记录只有一份；不能让
本帧选枝改变透射/反射身份，或把“选了反射”解释为 TIR。轻量使用自己的 F / 1−F
外观候选，同样只有一条照明路径。

## 距离与稀疏信号

距离描述实际观察：0 表示尚未追踪或没有可用命中，65504 表示已追踪的环境 miss，
有限距离从对应接收面或虚拟接收面之后的首段开始。RR 在观察前终止时不能伪造 miss。
相机到接口、接口到替代表面和替代表面后的散射距离分开保存。

少数深层路径采到太阳或亮灯会产生大权重；MIS 只合并拥有同一支持域的技术，不能
消除所有稀有路径。当前不采用 radiance clamp、恢复平方根 RR 或删除深层光传输项
来掩盖萤火虫。优化应先核对采样支持域、正反 PDF、重复 emission、距离语义与两路
guide，再比较等时方差和运动重建结果。

回归包括空/全活/稀疏队列、配置边界、线性 RR 的有限阶期望、STBN 离散小概率支持、
透明选枝、未观察距离与 miss 区分。测试准入见[测试与基准验证](测试与基准验证.md)。
