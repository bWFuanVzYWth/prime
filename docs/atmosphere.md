# 大气资产、更新与消费契约

大气沿用旧 Prime 调整过的四波长介质、逐次多散射、相函数、光谱到 Rec.2020 变换和艺术标定。物理输入来自 Sky Tracer `b66b16342afe38e788a5ece5371d3b3a67c5909a`；来源和许可证见 [第三方声明](../THIRD_PARTY_NOTICES.md)。这里描述生产路径；单次测量和对拍结果放 `artifacts/`。

## 源边界与默认值

两个 Java 适配器只发送实际 `skyRenderState.sunAngle` 和相机绝对位置。帧包末尾的原保留字成为 f32 太阳时角，单位弧度，ABI 升为 7，仍为 104 字节。`prime_minecraft` 解释时角，使用 Rust 的 `SolarOrbit` 按观测纬度、太阳黄经和旧轴倾角 23.43928°产生方向；默认纬度 30°、黄经 0°；`prime_scene::Environment` 只包含世界高度和单位太阳方向。Rust 负责失效与 GPU 调度。离线冻结同时冻结时角、纬度/季节、世界高度和视角。观测纬度范围 -90°…90°，太阳黄经范围 0°…359°；0/90/180/270° 对应春分/夏至/秋分/冬至（北半球）。季节沿用旧版手动控制，与游戏天数独立。纬度和赤纬的常量只在设置变化时由 CPU 准备，每帧只计算实际时角。

默认值保持地面半径 6360 km、大气顶 6480 km、世界 Y=-64 对应物理高度 300 m、世界单位 1 m、气溶胶密度倍率 1、太阳角半径 0.00471 rad、外太空太阳积分强度 12.5。世界高度到 f32 半径的转换点和大气内 clamp 与旧版相同。颜色输运使用 450/510/580/650 nm 四个采样点，最终为线性 Rec.2020；这仍是拟合近似。

物理介质和高度映射固定为上述调优配置；设置页的光照组提供纬度和太阳黄经。气溶胶编辑器、天气、月亮、星空和维度专属天空尚未接入。透明物体仍采用当前场景的 coverage 语义，不包含旧材质系统的折射与体积吸收；不能因此声明旧版所有场景外观已经等价。

## 资产

使用标准 Safetensors 容器，little-endian、无有损压缩。格式只有通用容器，物理语义由 metadata 明确规定；不从扩展名推断相函数的归一化或角度约定。

- `assets/atmosphere/medium.safetensors`：命名的 f32 高度、介质 profile、相函数、积分质量、求积节点及映射系数。相函数为 `sr^-1`，`mu=+1` 表示前向；坐标为 `u=cbrt((1-mu)/2)`，1024 个中心节点，在 u 域线性插值、端点 clamp。四类粒子、四个波长和原始浮点位模式保持不变。
- `assets/atmosphere/default.safetensors`：八轮、每状态 1536 个入射方向求解后的 optical depth、归一化 scattering source、incident mean、ground radiance、Rayleigh moments。前两者 f16，其余 f32，尺寸与旧版一致。

两份资产编入 native 库，启动只校验和上传，不重新运行多散射求解器。运行时将命名介质数组按固定 GPU 布局连接一次；shader 不解析容器、没有运行时解压。离线工具按原计算依赖生成资产，工具特性不编入默认发行路径。再生成命令见 [CONTRIBUTING](../CONTRIBUTING.md#大气资产与无窗口验证)。

## 更新依赖

| 资源 | 规格 | 失效条件 |
| --- | --- | --- |
| 物理场 | 约 6.7 MiB | 当前固定资产，仅首次上传 |
| 帧常量 | 每退休槽 400 B | 太阳、相机、投影、遮挡请求标识变化 |
| SkyView | 256×256 RGBA32F，log Rec.2020 | 物理高度或太阳仰角变化 |
| Camera-T | 8193×1 RGBA16F | 物理高度变化 |
| Aerial-S | 128×256×128 RGBA16F，约 32 MiB | 高度、太阳方向、相机位置/姿态/投影、场景内容变化 |
| Aerial-T | 128×64×128 RGBA16F，约 8 MiB | 高度、姿态、FOV、宽高比变化 |
| 遮挡列 | 五级 512² uint4，约 20 MiB | 太阳基、场景内容或有限追踪平面变化时整体失效；相机平移复用仍有效的世界网格列 |

依赖使用精确输入身份，没有时间阈值、低频更新或旧帧混合。静止且输入不变时全部 LUT 复用；太阳持续运动仍会刷新 SkyView 与 Aerial-S，相机旋转仍会刷新两份空气透视。资源在同一宿主队列按显式依赖更新和消费。描述符/帧常量仅写已完成的槽，资源退休沿用宿主完成值，创建失败与提交不确定性遵守现有隔离规则。

遮挡沿用旧版五级 0.5/1/2/4/8 m 网格、3×3 保守膨胀、2 cm bias、近级 512 / 远级各 256 项的极线剖面和可见长度积分。GPU 先原子标记剖面需要的 3×3 邻域，再通过硬件最近命中查询补齐请求列，最后读取 blocker depth 构建剖面；三个 pass 之间有显式依赖。无需维护旧版 Java 双银行、分帧瓦片状态或额外 min/max mip。列存请求代次、世界网格身份和 blocker depth，2 km 分片固定追踪平面，射线全长 8 km。未覆盖、剖面溢出及不可解析区间保持遮挡。当前场景任何内容变动会保守清空遮挡缓存，尚未做空间局部失效。

## 每条路径的消费

SkyView 的太阳仰角、地平线与三个 chart 系数按帧准备，查询只做方向映射、一次硬件双线性过滤和指数解码。太阳方向基预计算，有限圆盘按立体角均匀采样，Camera-T 硬件过滤并单独判断地球遮挡；可保留地平线上的部分圆盘。NEE 和 BSDF miss 使用一致的圆盘 PDF/MIS，最后允许的顶点只有 NEE 时权重为 1。

空气透视仍在 primary hit 合成 `L = T*L + S`，使用同一相机 jitter、实际射线距离、旧平方深度分层与近端权重，最大距离 2.048 km。T 用一次硬件三线性查询；S 对两个相邻极线各做一次径向/深度过滤，再沿极线插值。相邻极线的径向坐标不同，不能直接替换成一次普通三线性查询。可见极线范围提前计算，消费不再重复做四个角的 atan2 和排序。Sky miss 不重复叠加有限距离空气透视；S 随太阳强度设置缩放，T 不随曝光或太阳强度变化。

无窗口验证覆盖原光谱/SkyView 夹具、太阳圆盘及地平线、空气透视对直接积分、硬件过滤对显式插值、零距离、更新依赖、遮挡物添加/移除和 Vulkan 同步。游戏视觉、连续昼夜/跑图 p95 与完整帧数仍由用户在原生 1920×1080 验收，局部查询加速不能外推成整帧加速。
