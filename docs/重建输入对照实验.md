# 重建输入对照实验

后续透明单光照与双 guide 对照见[透明单光照分支实验](透明单光照分支实验.md)。该实验保留
本文用户确认有效的 DLSS 仅命中距离输入，以及 NRD 太阳 diffuse/specular 共用 SIGMA。

DLSS 仅命中距离方案经用户实测有改善，保留为固定策略；Lambert 共用该策略。NRD 太阳
镜面信号分流经用户实测出现严重高光阴影漏光，已删除实验代码和开关，恢复普通表面的
太阳 diffuse + specular 共用 SIGMA。离线光传输保持原样。

## 收敛后的固定策略

2026-09-06，用户确认透明单光照 + 双 guide 的画质满足需求，删除 RR 四档、首透明面
单光照、DLSS 反射仅命中距离三个会话控件。DLSS 永久给 NGX 的 reflection MV 传 null，
保留 specular hit distance、primary MV 与矩阵。

反射 MV 的 RG32F 图像、prepare 中的生成和专用诊断视图已删除。prepare 的 storage image
绑定从 17 个减到 15 个，不再读取反射虚拟位置，额外省下 `8 B × N`（内部渲染像素）：
1080p 为 15.82 MiB，4K 为 63.28 MiB。反射位置图像仍服务于追踪/guide 暂存，继续保留。
原生桥 ABI 11 的 optional descriptor 契约保留；生产提交固定为空。

## 两项固定修复

### 透明 DLSS 的 specular albedo

有有效透射替代表面时，主 guide 使用透射目标的几何和 diffuse albedo，但 specular albedo
必须保留可见接口的反射率。此前选择整组 transmission guide 会把它替换成目标材质的
specular albedo。现在选择函数显式恢复接口值。

纯 TIR 把有限反射目标提升为唯一主表面时，继续使用反射目标自己的 specular albedo。
NRD 两层分别使用各自目标材质的规则不变。

### 每像素 guide scratch 的步长

旧 ABI 声明 area guide 为 16 bytes，对应字 0..3；透明可见接口还使用字 4..7 保存
精确 f32 normal/roughness。因此接口写入实际落入下一像素的 area guide，最后一个像素
还会写进后续 surface 区域。不同阶段的写入顺序只能改变谁覆盖谁，不能让共存的数据安全。

现在每像素 guide scratch 为 32 bytes；surface/phase 区偏移、总 scratch 和 CPU 分配同步更新。
新增相邻像素写入及尾部哨兵 GPU 测试，原有整个队列布局性质测试继续检查各区边界。

完整实时布局从 `524 B × N + 112 B` 修正为 `540 B × N + 112 B`，其中 N 是内部渲染像素数。
当时路径槽为 112 bytes × 2，图像数量不变。此后单光照已将路径槽减为一个；这里仅记录
guide 越界修复当时增加的显存：

| 内部分辨率 | 增量 |
| --- | --- |
| 1920×1080 | 31.64 MiB |
| 2560×1440 | 56.25 MiB |
| 3840×2160 | 126.56 MiB |

这笔增量来自修复共存数据的越界。撤回太阳实验后仍需保留；普通像素不再使用字 4..7，
透明像素仍用它们保存可见接口。Lambert 的独立路径/队列布局不变。

## 已撤回的太阳 specular 实验

用户反馈：高光阴影出现严重漏光。2026-09-06 已完成撤回，该分流不再作为当前 NRD 输入策略。

代码核对确认：实验在太阳 specular 进入 noisy specular 前乘过当前阴影样本的 visibility，
并给它独立的 SH 方向矩；不是简单漏乘阴影。变化在于它随后与面积光/间接镜面辐亮度一起
通过 REBLUR 和 SG resolve，最终合成时 SIGMA 只约束太阳 diffuse。BSDF 首段 hit distance
也不表达太阳遮挡边界。因此高光可以在过滤/重投影中进入阴影区域；这与实测现象一致，
但尚无逐阶段抓帧证明 REBLUR 与 SG resolve 各自的贡献。

恢复后，普通表面的太阳 diffuse + specular 同属 unshadowed sun，合成阶段共同乘 SIGMA
visibility；透明主表面保持原有 noisy 分支。采样、BSDF、MIS、阴影遍历和距离语义均保持
实验前策略。移除了太阳专用控制位、scratch 读写及三路方向矩，保留面积光与 continuation
的两路方向矩。

不能把最终整个 specular 再乘 SIGMA 作为补丁：其中还包含面积光和间接照明，它们不受
当前像素的直射太阳遮挡支配；已经遮挡的太阳样本在半影处再次乘可见性也会改变亮度。
之前的数学与 ABI 测试只覆盖局部数值和数据契约，没有覆盖亮区/阴影相邻时的完整重建，
不能用这些测试通过代替画面验收。

## 验收重点

- DLSS：相机平移时普通金属反射是否更稳定；水面、玻璃和 TIR 是否退步。公开接口允许
  hit distance 替代显式 reflection MV，但不能据此保证对本项目所有透明近似都更好。
- NRD：确认回退后高光阴影恢复；相机静止与移动时均检查亮区到阴影的边界。
- 固定修复：玻璃前后的材质切换不能改变接口 specular albedo；相邻透明/不透明像素的 guide
  不互相破坏。
- 后续重建回归保持场景、分辨率、相机轨迹相同，并给重置后的历史足够积累时间。

尚未解决：DLSS 单套主 guide 对同时存在的透射/反射无法完整表达；太阳 diffuse 的随机
有色滤光仍不由 SIGMA_SHADOW 重建；深层照明的稀疏采样也不由本轮输入分流消除。
