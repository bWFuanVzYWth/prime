# 暗光深层反弹与萤火虫分析

2026-09-05。用户确认删除投影采样后帧数进一步提高。本轮为源码审查和数值复现，未更改生产
shader、RR 参数或降噪设置，没有新的 GPU 时间/寄存器捕获。阶段拆分、MSE、ReSTIR 暂不推进。

## 目标与结论

实时优化的是在短历史与运动条件下可以稳定重建的信号：避免长时间无样本、偶发极大补偿、
错误的 hit distance 和被滤成光斑的孤立亮点。离线优化的是**同一积分目标**下的方差乘每样本
成本；裁掉亮点或改粗糙度虽可降方差，却同时改变均值，不能按等价采样优化计收益。

| 顺序 | 项目 | 证据 / 预期 | 范围与代价 |
| --- | --- | --- | --- |
| 1 | 提高 STBN 的离散选择精度 | 正式表已复现窄概率区间漏采/过采 | 旧实时选灯和 cell；独立补低位，无需扩大表 |
| 1 | 区分未追踪的 hit distance 与 miss | Lambert 首次 RR 终止仍输出 65504 | 重建语义修复；不需要新图像或射线 |
| 2 | 对深层 RR 试验概率下限 | 解析模型能显著增加深层有效样本，平均射线数变化小 | 实时/离线分别验收；只改概率，保持补偿 |
| 2 | 实时 RR 按去调制信号衡量重要性 | 当前反照率衰减随后被 NRD 除回，放大稀疏噪声 | 首先在 Lambert 明确数据流；不能直接套旧透明 guide |
| 3 | 定位环境/星图与窄高光的罕见路径 | 天空/星图仅 BSDF miss 求值，星图固定 LOD 0 | 归因后选择环境 proposal 或新实时模型正则化 |
| 3 | world/local 树访问特化、弱化内部质心奇点 | 有确定热路径；质量收益需要场景验证 | 不改几何/材质；前后 PDF 共同改动 |

## 1. 16 位 STBN 不适合直接承担所有离散选择

`shaders/math/direct_sampling.slang:66` 解码为 `(u16 + 0.5) / 65536`。太阳/半球的二维方向可
继续使用这份表，但树选择是不断切分标量区间：`tree_select.slang` 将同一随机数连续重映射
穿过世界与局部树。移动像素、反弹、cycle 的查表地址都不会增加这个标量的可取值数量。

脚本 `tools/analyze_path_sampling.py` 读取正式 bank 0 的全部 1,048,576 个样本，得到：

- 标量仅有 65,536 个不同值，最小值 7.6293945e-6；每个 code 出现 16 次。
- 对 131,072 叶、每个二叉分支概率精确为 1/2 的树，仅 65,536 个叶可达。这是等概率可表示的
  合成树，二进制重映射全程精确，不依赖光源权重、树的误差或随机抽样运气。
- 概率宽度 1e-6 的区间，若位于 `[0,1e-6)`，全表命中数为 0；若包围一个 code，命中数为 16，
  而理想均匀输入期望为 1.048576。对应概率质量为目标的 0 或 15.2588 倍。
- 正反 PDF 使用的是浮点树 PMF，没有按这个格点分布修正。因而这里存在系统性的离散化误差，
  不只是低 spp 方差。场景变化使区间移动时，也可能从漏采跳到过采。

这些结果证明风险存在，**不证明实际当前场景有 131,072 个等概率灯，也不证明已观察到的
萤火虫主要来自它**。Lambert 尚无方块光 NEE，因此不受此项选灯问题影响。

纹理 alias 的 cellSample 也来自 16 位标量；一个 column 内仅剩 256 个可能的小数值，极小
aliasProbability 同样可能没有取样点。不能只修世界树，漏掉 cell 的选择。

低成本候选是保持 STBN 的高 16 位，在格点区间内用独立 hash 补 8 位，构成 f32 可精确表示的
`uint24 / 2^24`。新低位必须包含像素、帧、epoch、反弹/分支和维度身份；不能只 hash 旧 code，
否则仍只有 65,536 个不同值。不能复用方向/事件的随机数使终止或选灯与方向条件相关。

完整 24 位均匀格点在上述两个 1e-6 区间的概率误差都约 1.33%，等概率树所有叶均可达；这是
理想低位枚举，尚非实际 hash/STBN 组合的时空质量验证。24 位也不是无限精度；世界/局部层
独立随机数或更深层重新供给熵可另评估，不建议一开始给每层增加 hash 或新的大表。

门禁应覆盖：端点严格小于 1；高位分层保持；全部正式表/多帧低位覆盖；实际树前后 PMF；极小
分支与 alias；相机运动时的闪变。现有均值、16-bin 直方图和跨 bank 相关性测试抓不到窄区间问题。

## 2. RR 保留，但应区分相机像素权重与重建输入权重

共享规则在 `math/transport.slang:98`：`p = min(sqrt(max_component(beta) * etaScale), 1)`，
存活后 `beta /= p`。Lambert 从第一次 scatter 开始；旧实时 landing/fixed 明确跳过 RR，到 tail
admission 才开始，不能把两种模式都描述为“首跳 RR”。离线使用独立调度与 Sobol，RR 使用 hash。

当前 sqrt 规则比直接按 beta 存活更保守。不能把它换成线性 beta 当成无代价省射线：对暗材料，
线性规则会让罕见存活样本更强。etaScale 必须保留，避免把折射引起的可逆尺度变化当作吸收。
[PBRT 的 RR 讨论](https://pbr-book.org/4ed/Light_Transport_I_Surface_Reflection/A_Better_Path_Tracer)
也强调它增加方差，价值来自成本下降；选概率时必须一起衡量成本。

### 首反照率与去调制的冲突

Lambert 首表面的 beta 乘反照率 a 后做 RR；`entry/post/nrd_motion.compute.slang:223` 随后将
间接辐射度除以该反照率。考虑灰色反照率、恒定入射间接光 1，去调制后期望本应为 1：

| a | 首次存活率 sqrt(a) | 零样本比例 | 存活的去调制值 |
| --- | ---: | ---: | ---: |
| 0.001 | 3.16% | 96.84% | 31.62 |
| 0.01 | 10% | 90% | 10 |
| 0.04 | 20% | 80% | 5 |
| 0.25 | 50% | 50% | 2 |

估计器均值正确，但重建器收到的信号比未做这次 RR 稀疏得多。即使纯 Lambert 的存活 beta 不
超过 1，也不能据此判断没有易形成萤火虫的信号：后续明亮 Le 和首表面的去调制都还会放大它。
深层明暗还受可见性与传输影响，不能将“暗处”一概等同于“暗反照率”。

实时可比较两种简单政策：保证首个重建用间接样本；或者按去掉首表面调制后的重要性选择 RR
概率，实际 beta 仍按真实 p 补偿。后者更符合重建输入目标，但需要明确首表面/PSR、diffuse/
specular 的调制因子与状态所有权；不能把 etaScale 偷换成别的含义。离线没有 NRD 去调制目标，
不自动跟随这个调整。

### 深层概率下限比全局推迟 RR 更有针对性

先做 `p = max(p_original, p_min)` 的小范围 A/B；零 beta 仍直接结束，p=1 保持 1，无需强加
0.95 上限。改变 p 并按同一个 p 补偿，保持既定截断目标的期望。它增加的是深层实际抽样机会，
不是用更少反弹或裁亮点来掩盖噪声。p_min=0.25 只表示本轮解析实验点，不是选定的生产参数。

解析模型：8 次相同 a=0.2 的 Lambert 散射，终点有 1% 概率遇到单位光，途中无其他光照；
平均 trace 数包含一条相机射线。每次 trace 假定等成本，排除材质、遮挡和调度差异。

| RR 政策 | 到达终点概率 | 存活 beta | 平均 trace | 方差×trace 相对当前 |
| --- | ---: | ---: | ---: | ---: |
| 当前 sqrt，从首次开始 | 1.272e-5 | 0.2013 | 1.6228 | 1 |
| sqrt，从第二次开始 | 1.280e-5 | 0.2000 | 2.2500 | 1.378 |
| sqrt，下限 0.25 | 3.265e-5 | 0.0784 | 1.6255 | 0.390 |
| 线性 beta，从首次开始 | 2.560e-6 | 1.0000 | 1.2500 | 3.827 |

下限实验在此模型里使深层存活增加约 2.57 倍，平均 trace 仅增加约 0.17%。这说明“稍保留
低概率深层路径”可能比推迟所有早期 RR 更划算，不能把数字预测为游戏收益。这个刻意只在
终点发光的模型甚至会偏好完全不做 RR；真实画面还包含大量早期贡献，最优政策依场景而变。

每次补偿最多 1/p_min 不等于整条路径或像素贡献被限幅。RR 不能解决 BSDF/光照分布严重不匹配。

## 3. Lambert 的无样本距离目前伪装成了环境 miss

`entry/lambert/camera.raygeneration.slang:17` 将 radiance.w（第一条间接射线的 hit distance）
初始化为 65504。`shade` 的首个 RR 可以直接终止，因此从未执行 `trace` 中 identity.z==1 的
距离写入；最终 resolve 仍将 65504 送进 noisyDiffuse.a，再被归一化成远距离。

这应是 **0＝未取得距离样本**，而实际追踪后 miss 才是 65504。相机直接看天空属于 stable
radiance，不依赖这个 diffuse 距离，不能作为初始值采用 miss 的理由。修复不需要多追射线或
额外图像，但需要覆盖初次 RR 终止、零反照率、首次 hit/miss、后续 RR 终止保留已有距离。
此处记录发现问题时的状态；后续实施已修正初始值，见文末。

固定 NRD 4.17.4 的[接口说明](https://raw.githubusercontent.com/NVIDIA-RTX/NRD/9a3fe938a7558fd16b6c91a1c0456305cdcd9f16/Include/NRDSettings.h)
区分无效距离与有效样本，并要求概率跳过时给出 0。Prime 已启用 5×5 距离重建与 30/50 像素
prepass，但 hash RR 在任意低概率下不保证邻域有样本；修正哨兵解决语义，不会自动填补缺样。

## 4. 普通 MIS 无法解决所有深层罕见亮路径

现在 Area/Sun 有 NEE，命中灯/太阳有对应 MIS；天空和星图只有 BSDF miss 求值。星图在
`service/atmosphere/starmap.slang:34` 固定采样 LOD 0，包括很粗糙、很深的路径。若由这些方向
尖峰产生萤火虫，继续改善方块光选灯无效。太阳经过镜面/折射链聚焦到漫反射表面也是另一种
困难路径：局部直线 NEE 不能替代沿镜面约束转弯的光路。

候选按目标分开：

- 实时新模型：首次非 delta 散射之后，可评估受控的路径正则化、对粗糙间接路径过滤高频星图。
  保留相机直接可见细节和相机起始的纯 delta 链。它改变高阶传输，必须作为明确近似验收。
- 离线：优先更匹配实际环境辐射度的方向 proposal＋BSDF MIS，或确有必要时再考虑复杂焦散
  采样。环境 NEE 只能改善能直线连到环境的那个顶点，不会解决拐弯房间里的全部深层反射。
- 两者：如需新的方向 proposal，可以复用已有相机位置的大气缓存构建小型固定分辨率分布；
  proposal 的低分辨率只影响方差，最终 Le 仍取实际方向，保留完整支持。先证明环境是主要来源，
  不给所有深度无条件追加一条阴影射线。

[PBRT 的路径正则化实例](https://pbr-book.org/4ed/Light_Transport_I_Surface_Reflection/A_Better_Path_Tracer#PathRegularization)
展示了仅在非镜面事件之后扩大后续 lobe 的动机。这里不能只调用现成的
primeSamplePathSurfaceWithMinimumRoughness：当前生产传 0，NEE evaluate 也独立使用原粗糙度。
只修改 sample 会让 sample/evaluate/PDF 不匹配。旧 OpenPBR 的数学与参考合同继续保留，新实时
的近似应在明确模型入口处理，不能静默扩散到离线。

## 5. 仍有收益可疑的开销

**更强的反萤火虫抑制。** NRD 固定版本的 REBLUR 默认已启用 anti-firefly，Prime 又把相对抑制
阈值从默认 2 调到 1.5。继续调低会加偏差，可能将本来就很少的有效深层样本当异常删掉。固定
头文件也说明 prepass 会将极稀疏亮点摊成光斑。优先降低输入的尖峰/缺样，不能只增加 blur。

**所有深度全改 STBN。** 旧实时光照用 STBN，BSDF 用 Sobol，RR 用独立 hash；Lambert 的余弦
散射另用了 STBN。低维蓝噪声的优点不自动推广到高维路径，也不自动保证筛选存活样本后仍有好
的时空分布。[NVIDIA 的 STBN 讨论](https://developer.nvidia.com/blog/rendering-in-real-time-with-spatiotemporal-blue-noise-textures-part-1/)
明确区分低维低样本用途与高维/高样本积分；不建议为“统一”而改离线 Sobol。

**更复杂的叶几何度量。** 目前终端 emitter 读几何并构造 AABB/法线方向界；内部节点却只按
质心方向和距离。这些更精细的叶计算无法修正上层已经分错的概率。内部质心接近接收点时，
p/r² 还可能独占概率；1/256 是角度乘数 floor，绝不是最终选灯概率下限。
可以先将 world/local 读取显式特化，再比较低成本的内部节点尺度约束/温和权重压缩与当前
尖锐 proposal。不得直接把“不可见”和“估计小”混为零，正反树概率须同步；不先引入遮挡缓存。

**旧 tail 与无 RR 前缀。** 重型 tail 的寄存器与线程组长尾会影响暗处效率。现有 fixed-count
设置同时改变调度和开始 RR 的时机，增大它不能当作只优化 GPU 调度的实验；应记录存活路径
和样本质量一起比较。新轻量 renderer 已无 tail，本项不适用它。本轮不恢复阶段拆分工作。

## 实施建议

先修离散选择精度和未追踪距离语义，形成没有新显存/队列的基线。之后单独实验深层 RR 下限，
实时重点看相机转动、暗处抬曝光、深反射的闪烁和恢复时间；离线比较同场景等时统计。实时的
去调制 RR、间接正则化与环境 proposal 再逐项加入，避免把收益混在一起。

不增加常驻 cache、全尺寸诊断图或阶段缓冲。脚本的结果保存在 build/path-sampling-analysis，
它是读取正式表和解析 RR 的独立调查工具，不替代 GPU 分布、渲染图像或性能验收。

## 2026-09-05 实施：离散 STBN 与去调制 RR 实验

用户授权补低位、修 Lambert 距离并测试去调制 RR，随后明确将完整实时 PT 一并纳入；离线 RR
保持原策略。阶段拆分、MSE、概率下限、间接正则化和环境 proposal 均未加入。

### 离散采样

完整实时 PT 的 world/local tree 和 texture-cell alias 使用
`u = ((stbn16 << 8) | hashLow8) / 2^24`。高 16 位保持原表秩序，低 8 位在单独的 hash 域中，
由完整 pixel、sampleIndex、epoch、vertex、branch 和维度产生。不是对原 16 位值或周期地址做
确定性扩展；跨 128×128 平铺和 64 帧周期仍能变化。即时 tail 复用已有 prepared sample 的
完整身份，不增加持久 seed；分阶段选灯/采点在实际使用处计算。两个离散维度有标量专用入口，
选灯只计算 tree 标量，direct 只计算 alias 标量。

24 位整数转 f32 再乘 2^-24 精确给出 [0,1)，不加会把最大值舍入到 1 的半格偏移。太阳方向、
面内位置、Lambert 余弦方向继续使用原 16 位开区间 STBN；RR 独立 hash 和离线 Sobol 均不改。
这消除了原来的 16 位硬限制，仍然是有限精度采样，不承诺任意小概率的无限支持。

### 去调制存活概率与状态

统一数学叶计算 `p = min(sqrt(etaScale * maxRGB(beta / G)), 1)`。逐通道相除后取最大值；beta
包含此前 RR 的全部补偿，G 是固定重建调制因子，不是当前 bounce 的材质。实际路径权重只做
`beta /= p`，没有裁剪 radiance/beta，没有新的 p_min 或 0.95 上界。etaScale 保留原折射含义。
beta=0 的通道贡献 0；G=0 且 beta>0 保守取单位存活概率；分支先比较再除法，避免极小 G
导致中间溢出。所有非零运输只要随机命中存活，仍按同一实际概率补偿。

Lambert 的 G 为首表面反照率，使用路径三个既有 w 槽；128 B stride、队列和 payload 不变。
首表面 beta=G 时 p=1，黑表面直接结束；后续按归一化且已补偿的权重继续 RR。G 仅在阴影
追踪结束后读取。距离初始为 0，只有第一条真实间接 trace 写入 hit 或 65504 miss，后续
trace/RR 不再覆盖它。

完整实时 PT 保留固定无 RR 前缀，修改 tail admission 与 tail 内的 RR。普通路径根据首次
guide 的 diffuse/specular 分类读取对应主图像；NRD 透明分支读取各自的透射/反射 guide。
非 NRD 下按既有 resolve 合并规则选择：透射使用主 diffuse，普通反射使用可见界面的
specular，已有目标 guide 的纯 TIR 使用主图像的对应通道。每次只加载所选 RGB，不新增图像
或路径字段，不将完整 guide 对象带过 trace。路径事件发生在后续表面时，不重新选择首信号分类。
guide 在 tail 入场前已发布，并在整个 tail 中保持；缺少替换目标时沿用已有界面 fallback。
非 NRD 可见 specular 使用的阳光 scratch 图像加入既有 next-step barrier，确保 split 写入
在 tail 读取前可见；没有新增 barrier 提交点。

固定/landing/split 之前始终以 skip=true 调用通用推进，本轮删除这些无效参数及其未使用 RR
闭包，让 RR 只存在于实际执行它的 tail 位置。未改变各阶段 bounce 计数、随机映射和前缀长度。

GPU 验证覆盖正式 STBN 表的高位不变、低位分布/身份变化、17 层等概率树和小 alias 概率，
以及彩色/零/极小 guide、etaScale、补偿、12 阶积分期望和距离状态。新增产物与寄存器待测项
记录在[轻量渲染器寄存器记录](轻量渲染器寄存器记录.md)。实际画面稳定性、深层恢复和帧时间
仍需同场景捕获；更多路径存活会增加工作量，不能仅凭数学测试宣称帧率提高或萤火虫已消除。

## 2026-09-06 实时 RR 四档对照

以下为已结束的实验记录。用户验收后固定线性 RR、单光照与双 guide，三个调试控件和备用实现已删除。

视频设置 → 诊断 → **实时俄罗斯轮盘赌（测试）** 提供以下顺序，默认仍为带补偿平方根。
仅本次会话有效，切换重置实时积累与重建历史，同时作用于完整实时 PT 和 Lambert。

定义 `m = etaScale × maxRGB(beta)`，`g = etaScale × maxRGB(beta / G)`：

| 选项 | 存活概率 |
| --- | --- |
| 线性 RR | `min(m, 1)` |
| 平方根 RR | `min(sqrt(m), 1)` |
| 带补偿线性 RR | `min(g, 1)` |
| 带补偿平方根 RR | `min(sqrt(g), 1)` |

这里“补偿”指首表面去调制，G 的来源与上一节一致；四档的存活路径均使用 `beta /= p`。
当前顶点光照仍先结算。起始时机、固定无 RR 前缀、反弹上限、etaScale、随机数到 RR 的
映射和 NEE/BSDF 采样都保持不变。Lambert etaScale=1；两档带补偿模式在非黑首表面仍有
p=1，普通两档允许第一次散射后即终止，相应未追踪首段距离继续保持 0。

普通线性/平方根分支显式绕过完整实时的 guide 选择和图像读取；Lambert 也绕过首反照率
的三个 w 槽读写。带补偿分支继续使用先比较后除法的数值边界，不新增 p_min 或强制概率上限。
离线入口继续使用原来的平方根 RR，且不会读取这两个新增的实时模式位。

模式使用现有 `path.x` 的位 29..30；默认值编码为 0，默认和离线的 push 字节不受影响。
不增加路径记录、图像、队列、随机维度或 GPU 提交。四档共用一个 shader 产物，分支条件在
帧内一致；这便于即时对照，但驱动分配的寄存器可能仍受最复杂分支支配。最终选定策略后
才能通过删除其余分支衡量完整的寄存器收益。

对照时固定场景、内部分辨率、前缀长度和重建器，分别观察暗处深层反射的恢复、闪烁/萤火虫、
运动拖尾及 GPU 帧时间；切换后给历史足够积累时间。DLSS 仅命中距离仍默认开启，NRD 太阳
仍由漫反射和高光共用 SIGMA，避免把已结束的重建实验混入本轮对照。

验证：`gradlew build shaderTest nativeTest` 的 636 项测试通过，包含四档存活概率和各档
12 次散射的解析期望、原随机映射、实际 push 字节隔离。静态指令增量和 Slang 手动拆分
记录在[寄存器记录 L5](轻量渲染器寄存器记录.md#l5-实施实时-rr-四档调试)。

## 2026-09-06 采用线性 RR

用户实测线性 RR 性价比最好，另外三档依次变慢且未体现明显优势。完整实时、Lambert 与
离线均改为线性存活概率 `min(maxRGB(beta) * etaScale, 1)`；Lambert 的 etaScale 为 1。
离线只改概率曲线，起始时机、随机映射、bounce 上限、光照结算和 `beta/p` 不变。
实时四档开关暂留，默认 LINEAR 的 ABI 值仍为 3；此前“默认编码为 0、离线保持平方根”的
记录描述上一轮状态。本轮默认编码为 3，离线不受实时调试开关影响。

首透明面另启用[单光照分支实验](透明单光照分支实验.md)，以完整的双 guide 比較普通线性
与带补偿线性 RR 对运动重建的影响。选枝的 `1/0.5` 与 RR 的 `1/p` 是两层独立重加权；
不把 guide albedo 乘 2，也不把首面已有 NEE/emission 再乘 2。
