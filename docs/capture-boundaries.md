# 源路由边界与批量数据流

## 路由与截断

源路由同时转交输入并截断对应下游计算。长期目标保留模型定义/选择、姿态、材质与源颜色的必要扩展；当前 section 原型已接入实际 tint 批次，剩余默认替代见独立 hack 清单。动态模型路径仍保留实际源回调。具体顶点变换、展开、光栅明暗、三角化及针对这些下游实现的修改不属于兼容范围。

截断单次几何提交，不跳过后续仍会设置姿态或提交其他部件的外层模型回调。模型自身生成/修改局部网格属于源定义；不能把已经包含相机、光照或下游变形的最终顶点冒充可复用局部模型。没有接入的源类别须明确标注；不得为兼容下游修改恢复整条 Java 编译，也不通过再次运行有状态回调猜测输入。

Rust 的版本适配层解释宿主源字段并管理请求，场景和渲染核心消费自足的版本无关数据。源响应返回后不保留 Java 输入借用，编译不查询 MC 或反向调用 compiler。Java 保留字段绑定、源身份和封包所需状态，不拥有另一套地形窗口或编译调度器。

## 地形源输入与编译职责

当前为 Rust section 原型。Java 在原版 section 编译之前接管，原版 `SectionCompiler`、地形 BufferBuilder、光栅 AO/明暗、透明排序与遮挡图仍被截断。`ExclusiveTerrainCapture` 只转录相机/视距设置、宿主缓存边界、加载/卸载/dirty/失效事件；[`ChunkManager`](../crates/prime-minecraft/src/chunks.rs) 独立拥有活动范围、自持源、可用性、依赖失效及编译队列，内部调度器决定源需求和按格轮转选择。`TerrainContext` 负责解码、资源目录和同步编译/颜色事务；管理器不查询宿主，也不执行 GPU 资源操作。未来 LOD 尚未实现。

每个源帧调用一次 `prime_mc_plan`，Rust 返回实际需要读取的 section 及供动态源使用的活动列变化。Java 按坐标取得 palette/位存储，以 typed 数组用一次 `prime_mc_sections` 返回；新增资源先通过独立 `prime_mc_resources` 事务发布。Rust 展开可见几何时按实际 block tint slot / fluid source 收集需求，只有非空时再返回颜色源批次。Java 返回标准源类别、实际状态属性、常量字段及首次需要的群系 seed/色表/噪声字段；未知源保留真实回调 ARGB。Rust 自行完成原版红石/茎求色、群系 zoom、修色和混合，仅为缺失 quart 单元批量读取真实群系字段；已解析原版路径不执行宿主颜色回调。Java 不扫描颜色工作集、不计算几何，不进行逐段或逐 quad FFM。颜色未返回的片段保留在 Rust 明确的待响应所有者内，完整验证后才允许归并发布；编译 worker 始终不访问宿主。

源读取、资源解释和邻接/颜色/接触失效先按原事务完整处理；随后 CPU 网格编译每帧最多选择 N 个世界对齐的 4×4×4 section 格，默认 8、可调 1–128。待办只保留格身份及 section 脏位，重复变化合并，轮到时读取最新自持源；同格所选脏段一起编译，颜色/群系响应轮次不另取额度。公平轮转避免持续编辑饿死其他格。移除立即撤销待办与可用性，epoch 取消旧工作，不把未编译段伪装为完成。后段另有相同上限，完整语义见 [每帧构建预算](spatial-batching.md#每帧构建预算)。

输入分为 section typed 数组与独立资源批次：

- 原始 section 以 palette 中的真实 state ID 和原始 packed longs 传输，Rust 解码索引；缺失、空段和非空段分别处理。邻域 halo 只提供依赖，不会作为额外地形发布。
- 资源字段包含实际烘焙 quad 的位置、packed UV、tint 索引、层、实际 sprite 身份与 material emission，以及 SingleVariant / WeightedVariants / Multipart 的结构引用。multipart 首次出现时读取宿主已缓存的选中列表；未求值时只在 owner 的资源准备阶段调用一次实际 selector，并写回同一宿主缓存，保持每个模型内部的回调顺序，不按位置重放。其余字段读取不调用 emission。Sprite 资源一次转录实际帧/mip 像素与时长，源帧只增加实际 game time；关系和动画求值不放进 Java。
- 遮挡源来自 state 初始化时缓存的面形状坐标/占据网格与支撑位；液体源来自 state 的流体身份/属性、实际 FluidModel、sprite 身份/区间、状态发光和实际玻璃/树叶类型标志。按源身份去重，资源代次内只传一次；Java 不合并形状、不计算流向或液面。
- `prime_minecraft` 按版本解释种子、随机选择、模型图、剔面与液体邻域规则，先解决重复/正反/覆盖与邻接接触，再生成版本无关 quad 表面。本轮默认/随机替代及兼容缺口仅列在 [原型 hack 清单](../PROTOTYPE_HACKS.md)，不视为原版等价或完整回调兼容。

标准模型放置声明随首次 state 定义传输：Java 绑定实际 offset 函数类、常量限幅方法声明与 seed 状态属性，Rust 在位置上执行 XZ/XYZ、DoublePlant/Door/Bed 规则。未知 lambda/方法覆写保留近似及独立诊断，不重复求值以推断规则；标准方法体的第三方 Mixin 改写不在当前保证内。资源代次内不变声明只准备一次，源版本和16字节布局见 [ABI](abi.md)。

原生只在窗口/来源成员变化时更新活动集合，按列求差后只增删变化列及变化高度范围的 section 身份；没有待编译积压的稳定帧只交换批次头与时钟，没有全世界扫描、section 数据请求或编译作业；有积压时继续按预算编译，必要颜色源仍通过显式批次取得。时钟变化时只更新相位实际变化的动画；资源准备缓存累计时长，同相位不重建 mip/材质视图。缺失响应保持缺失，由实际 dirty、列替换、重新进入依赖范围或资源失效重新请求，不因无关的相机移动重试全部缺失段。

普通 dirty 事件在 Rust 合并，压缩状态相同不重编译。标准群系原始样本和混合结果在 Rust 按实际位置/解析器分层缓存；整数前缀和与原版逐点累加数学等价，Java 不计算混合。颜色独立依赖宿主的 `onChunkLoaded` / `clearTintCaches` 通知（包括群系包与混合设置变化），列卸载也使缺失列回退依赖失效。失效列先去重，再过滤实际消费过 tint 的活跃段；按群系 zoom 的2格边界及混合半径撤销相关位置，未受影响的邻列颜色继续复用，不会为颜色变化重发方块 palette。变化段自身进入工作集；边界体素比较面形状、透明同类规则、流体高度/身份、实心/overlay/支撑、模型/发光/光学与占据语义。变化位于段面、棱或角时分别使相关活跃面邻段、对角邻段失效，内部编辑不连带编译邻段。依赖范围覆盖完整一格邻域，列缓存包含八个水平方向；依赖列本身不成为活动渲染列。资源失效仍重新解释全部活跃输入。该比较与编译器必须消费相同的依赖语义；未来接入其他规则或回调时同步扩充依赖，不能沿用较弱的失效证明。

每个选中的非空段分4个高度片，在 session 共享 CPU 池完成普通剔面和必要接触；颜色批次处于同步阶段之间。普通接触产物若没有复合/介质等扩展属性，也回到紧凑 quad。普通 quad 片段保留独立 Vec/Arc 并复用精确相同的片段；复杂面独立保存关系，不为每个普通面附加稀有属性。回填后比较并发布自持的 `CompiledSection`。本批纹理与所选几何在同一次有效发布中可见，验证失败不推进完成水位、确认所选脏位或轮转游标。未选中几何留待后续源帧，不保留跨帧 Job 或编译完成证明。旧 CPU 引用同步释放或在同一池 join，GPU 完成另行证明；诊断分列 kernel、finalize、publish 和 retire。

压缩源缓存不扩展为整个世界的解包副本；每个作业只降低当前 slab 和一格邻域（含液体需要的边/角；无流体局部 palette 只降低面邻域），复用 palette 分类与模型面掩码。slab 工作区采用 SoA，分别存储模型/流体输出掩码、遮挡掩码和不可变状态引用。完整面与空面由紧凑掩码剔除，部分形状和透明同类规则仍读取源状态并执行精确判断；流体仍消费完整邻域，不用方块剔面掩码代替液体语义。模型选择仍使用原有位置种子，完全被剔除的模型无需展开；保留面仍保持原剖分与逐角属性；双侧/覆盖面有各自颜色绑定，跨作业按位置/state/slot 去重实际源请求。图层精确比较位置、颜色、UV、材质和原点，相同时保留原 Arc / 内容版本；内容证明绑定场景 owner、epoch、revision 和完成水位，不能跨上下文或发布后重用。已完成几何交给现有4³整体 BLAS通路。

地形模型和流体从中间输出到不可变逐段缓存、翻译快照和整格计划均保留四角位置/UV、单份一致色与材质，颜色回填按 quad 写入。`MeshGeometry` 共享紧凑四边形或完整三角形的 Arc；一致色 quad 为 104 字节，两个完整三角形为 232 字节。逻辑数量和范围始终以三角形计，消费视图按 `0-1-2 / 2-3-0` 取角，容量划分可落在一对三角形之间；非共面四边形也保持原绕序。GPU 打包统一写完整或退化 quad 记录，不另存展开缓存；固定两个 primitive 槽直接寻址。其他来源的逐角颜色仍使用完整三角形；精确内容比较、Arc 身份保留和完成证明不变，跨表示的相同几何同样保留旧内容版本。

编译工作只借用不可变资源字典和封闭 section 快照，输出作业独占几何；没有世界查询、FFM、源回调或全局可变缓存。源准备（包含必要回调）、调度/失效、纯编译、带完成证明的发布分别由明确 owner 执行。未来 LOD 或编译缓存应以资源代次、源内容、邻域依赖及编译策略为输入身份；禁止只凭 section 坐标复用结果，也不能在内核中懒执行宿主副作用。

第一次静态提交仍等64个实际段位置全部可用，真实空段计入、缺失段不计入。源请求和 CPU 编译不等64段齐全才执行。后续编辑按预算更新逐段缓存并整体替换对应静态格，跨格修改不保证同帧可见；窗口退出/卸载立即撤销可用性和数据，重进按实际宿主状态请求。

离线冻结暂停尚未发布的 CPU 编译待办；未知 tint 或缺失群系来源不能通过隐式宿主回调补齐。冻结快照中已发布源的后段构建可继续，实际几何内容变化会重置累积，等价 OMM 重建不会。返回实时后恢复显式源事务，世代切换仍取消旧工作。

真实资源全局失效重建资源字典并失效旧几何；世界重置清理世界源但保留canonical资源，renderer结束时释放其native资源所有者。catalog 显式整代换新成功后递增 `scene.terrain_resource_generation`，同批撤销尚未用新目录编译完成的旧 section 几何；自持压缩源保留，后续按格预算重编，新代仍须取得包含真实空段在内的 64 份完成证明才能发布整格。后段立即撤去旧代驻留格，不能让旧 UV/材质消费新资源目录；当前机制中的普通纹理身份撤销也立即撤去仍引用它的旧格。普通编辑和动画不推进资源目录代次。接触编译能力由流体字典、实际 state 玻璃标志和准备后的模型掩码派生，资源定义发布时更新；只新增流体时也刷新，字典换代时重新派生。slab 消费缓存的能力布尔值，不重复扫描不变资源字典。宿主字段准备与颜色求值各有明确批次；必要的 state-bound selector 在资源准备内完成。自定义模型与任意外部颜色依赖尚无完整批次/失效契约；编译和渲染层不反向查询宿主。

## 源资源复用

地形 Java 只维护源对象/状态到 typed ID 的映射及宿主既有的资源选择结果，不缓存展开几何。Rust 持有实际字典和压缩页。资源定义在代次内不可变，原地改写同一 ID 会在发布前拒绝。现有 op12/op13 只在 Rust cfg(test) 和 Java testFixtures 保留；生产 CaptureInbox 不含历史地形队列，发行包不带旧路由。

地形纹理在初始化/真实资源重载时通过独立资源事务登记为全局常驻，普通section引用变化不退休它们；world reset保留canonical资源，renderer restart重新建立对应GPU所有者。动画采样状态与像素寿命分开，同相位复用已有视图。动态皮肤、地图等仍按实际上传/关闭与源引用管理，不能覆盖常驻terrain ID；在途CPU/GPU使用保持独立的完成证明。

展示模型 wrapper 的 Fabric geometry-key 缓存与动态实例通路继续保持原契约：实际 tint、材质和变换仍参与提交，可变源不能仅凭对象身份复用。这一动态路径不使用地形原型的模型替代。

## 模型、物品与粒子

模型在 `ModelPart` 调用每个 `Cube.compile` 之前读取实际局部 polygons 和已求值 pose，发布 typed 原型/实例批次，随后截断该次虚调用，包括 Cube 子类的下游 compile 覆盖。外层 `setupAnim`、模型遍历及后续姿态设置继续执行。资源顶点引用变化才重新读取局部坐标；原型共享不意味着任意不同资源身份都会去重。consumer、UV 或非空 polygon 布局无法解释时明确失败，不猜测材质或重播下游实现。仿射合法性由 native 入参验证；当前实例通路要求有限可逆变换，奇异姿态不静默丢弃，也不在 Java 补算。

普通 item 在实际 `putBakedQuad` 调用点路由本次局部位置、UV、QuadInstance 颜色及 pose。统一 tint 保留在实例记录，逐角 tint 保留为局部源颜色；按本次材质、tint 和 pose 分组，内容相同可共享原型。未知下游 consumer 明确拒绝，不调用它补算；foil/outline 与特殊投影仍不属于普通源通路的完整支持范围。

Fabric 不可变 Mesh 通过公开 `forEach` 读取源 quad，不要求具体 MeshImpl 类型；在 `outputTo` 调用前按源 layer/tint 连续分组路由。材质回调沿源组顺序调用，实际 BufferCache 保留相邻 layer 复用。多层源受支持；未知材质不能静默用白色替代。source 与实例上下文分离，几何变化、成员消失、epoch 退出分别解除引用，GPU 回收另等完成证明。

标准 quad 粒子在 `buildLayer` 调用前按实际 layer 读取已提取参数：位置、四元数、尺寸、UV、RGBA。每粒子传 52 字节，省去源记录中的光栅 light；同层合为 typed 动态批次的参数 span。Rust 归一化旋转语义并构造四角/三角形，Java 不执行 `renderRotatedQuad`、逐顶点旋转或顶点编码。粒子 tick、碰撞、姿态选择和提取仍属于真实上游。GPU 展开可后续测量接入，当前展开在 Rust 同步池完成。

`PrimeDynamicBatch` 在 native 边界用自持的已验证字段值和 authored 顶点字节识别重复快照；C padding 与指针地址不参与内容证明，分开维护观察序号与几何内容版本。完全相同的输入复用解码结果及分桶；仅原点变化复用局部几何，但仍更新位置相关计划。实际源回调与 Java 封包照常执行，变化输入仍完整验证；不能以对象身份缓存代替可变字段观察。源证明不借用 Java 地址，纹理引用、旧 CPU 快照和 GPU 资源仍按各自真实消费者退休。

尚未提供更早源描述的自定义直接网格提交，仍通过 `Draw.append` 作为显式原始网格来源；这不提供对标准模型下游 consumer/展开改写的兼容保证。原始网格与参数粒子共用 typed 动态快照，持久实例使用独立 typed 实例增量。已路由标准叶节点不再产生重复 raw 顶点。手/HUD 属于宿主路径。

## 上下文、空间与完成证明

源资源、世界身份、帧观察、native 发布和 GPU 生命周期分别管理。Java 的成功封包只证明输入已自持；FFM 返回证明借用已消费；CPU 内容发布、命令录制、宿主提交和 GPU 完成仍是不同事件。资源定义可在同步编译后退休，上传/AS/输出依其各自最后消费者回收。

源变化按事件触发，未变化实例不发包。源读取与校验事务不使用跨帧数量/时间配额，重入事件进入下一批；已自持源的网格编译与构建按格预算推进。没有后台翻译、全局共享可变缓存或主动源背压；实际 GPU 在途依赖仍保留。边界验证失败不发布该记录，失败批次不确认生产者水位。

空间分组完全由 Rust 决定：静态和动态均按世界原点对齐的 4×4×4 区块段网格，静态每个完整格使用一个 BLAS，CPU 保留逐段缓存，更新整格替换。Java 不知道桶/BLAS 归属，GPU 不知道 MC 区块，见 [空间合批](spatial-batching.md)。不把所有实体合为一个有大量空隙的 BLAS。

方块实体候选索引由列/成员生命周期维护。已知默认距离类型查询邻近列，幸存者仍执行真实 dispatcher 的球形谓词；未知距离、getter 或外逃可变 map 保留完整源观察，全局对象独立处理。这里的源资格与下游计算兼容范围不同。

## 验证边界

双版本 Fabric CPU 夹具在游戏 main 前退出，实际读取 MC palette 和 baked quad，经 FFM 发布64段完整单元；验证空闲零请求、重复 dirty 合并、相同状态零编译、solid→air，以及未知模型不执行回调。Rust 读取两版夹具检查位置、UV、材质、颜色和完整格可用性，另测窗口变化、负坐标、halo、坏包与生命周期。新的差分入口实际调用两版 SectionCompiler（含 Fabric/Indigo），关闭 AO、统一光栅明暗。未改变的语义严格对比三角形多重集合；流体等已声明修复用独立表面查询比较位置、UV/颜色和占据，不能要求原版光栅背面数量不变。增量、原版源字段、两侧关系、光学和 GPU 消费分别验证，具体容限与范围见[测试契约](guides/section-tests.md)和[表面编译](surface-compiler.md)。当前夹具未加载完整原版资源包，不代表任意自定义模型/回调兼容。

真实游戏画面、编辑响应和帧率由用户手动验收。性能基线为原生1920×1080，固定场景和预算；CPU测试不能证明FPS或完整模组兼容。命令见 [CONTRIBUTING](../CONTRIBUTING.md)。
