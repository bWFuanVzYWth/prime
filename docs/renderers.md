# 设置、实时渲染与离线快照

## 控制与配置边界

版本适配器在原版视频设置中提供 Prime 设置入口，按渲染、光照、显示、诊断分组。控件使用该版本的 `OptionInstance`；公共 Java 层仅持有不可变值、当前配置编解码和设置封包。Minecraft 类型和按键回调不进入 Rust。

`config/primept.properties` 是当前 schema 的完整快照。当前版本为 2，`version` 必须精确等于 `RenderSettings.VERSION`；版本缺失、不匹配、字段缺失、类型错误或越界时，整份回退默认值并记录原因，不迁移历史字段、不拼接部分旧值。保存采用同目录临时文件与原子替换，文件系统不支持原子移动时使用替换。关闭设置页时保存；离线开关和诊断视图仅属于本次会话。启动显式指定 `primept.renderer` 时覆盖保存的渲染器选择；未指定则使用配置。设备特性仍必须由 `primept.enabled` 在启动时协商，设置页不能补开未启用的设备能力。

| 控制 | 范围与默认值 | 冻结时行为 |
| --- | --- | --- |
| 路径追踪 | 默认开；启动能力开关独立 | 切原版会结束快照 |
| 最大路径顶点数 | 1–64，默认 4，含首次表面命中 | 固定于快照 |
| 离线每帧采样数 | 1–64，默认 1；实时固定 1 | 可修改，保留累积 |
| 观测纬度 / 太阳黄经 | -90…90° / 0…359°，步长 1°，默认 30° / 0° | 固定于快照 |
| 太阳、天空强度 | 各 -8…+8 EV，步长 0.25，默认 0 | 固定于快照 |
| 显示曝光 | -12…+12 EV，步长 0.25，默认 0 | 可修改，保留线性累积 |
| primeDRT 色相、饱和补偿 | 0–100%、0–50%，默认 75%、8% | 可修改，保留线性累积 |
| 实时诊断 | 最终输出、噪声色、线性深度、世界法线 | 离线不分配这些纹理，禁用诊断选择 |
| 深度预览范围 | 1–4096 方块，默认 128 | 只改变实时预览映射 |

设置只在值变化时通过一个复用的 56 字节 FFM 包发布；稳定帧没有设置 FFM 调用。native 验证版本、枚举、有限性及范围后应用；非法 ABI 包报错，不改变已生效配置。配置文件的默认回退与 ABI 输入拒绝是两个不同边界。

## 互斥后端和快照有效期

原版、Prime 实时、Prime 离线分别是可选渲染模式。原版与 Prime 的宿主所有权交接见 [流水线](pipeline.md)。Prime 内部共用一个场景核心：源场景、翻译缓存、纹理、BLAS/TLAS 属于公共场景；管线、描述符和屏幕大小相关输出属于选中模式。实时仅分配噪声/深度/法线图像，离线仅分配线性累积 buffer，不为未选中的模式保留私有输出。

`Ctrl+Alt+F2` 只处理按下事件并消费该事件，避免触发 F2 截图；键盘重复不会来回切换。它和设置控件都只提出请求，在 `GameRenderer.extract` 外层帧边界执行。Esc 保留原版菜单行为，不结束离线模式。冻结不暂停游戏逻辑或服务器；HUD、菜单仍由宿主绘制，离线隐藏实时手部。

进入离线需有成功录制且尚未被后续源提交修改的帧；尚未就绪时 Java 保留请求，等待首帧。停掉世界提取、几何缓存及源编译调度后，宿主提交并等待旧命令完成，native 退休旧模式的输出/管线，再创建新管线。完成证明失败会阻止继续使用该 session。共享几何和 AS 不重传，也不重建。

native 固定上一帧的场景、世界位置、相机基、FOV、路径预算、光照和种子，拒绝冻结期间的 `prime_submit`。后续仅消费目标宽高与采样序号；Java 不发布场景增量（包括 op6/op7/op12/op13），native 不扫描/规划几何更新。每帧仍需录制命令并由宿主提交。宽高变化改变相机宽高比并重建累积，不改变冻结姿态。

资源生命周期独立于世界提取：Java 保留共同资源源缓存，继续观察实际纹理上传，供解除冻结后使用；这些变化不会写入冻结的 native 场景。块图集世代变化结束快照，避免跨资源重载沿用捕获身份。世界退出、切原版也结束快照。解除冻结先退休离线私有资源，再恢复实时捕获并发布新源 epoch，重新取得当前世界几何和已观察的资源；不重放有状态回调，不从 GPU 反读像素。

## 实时纹理与诊断

实时积分器每像素每帧计算一个样本，直接写三张同尺寸 storage image，没有时间累积。三个输出共享同一 jitter、alpha coverage 判定和首次命中：

| 输出 | Vulkan 格式 | 语义 |
| --- | --- | --- |
| noisy | RGBA32F | 线性 Rec.2020 D65 辐射亮度，曝光与 primeDRT 之前，alpha=1 |
| depth | R32F | 主命中位置相对相机的正向 view-Z，单位为方块；miss=`FLT_MAX` |
| normal | RGBA32F | 单位世界空间表面法线，朝向入射方向的反侧；当前 Lambert 粗糙度 alpha=1，miss=0 |

纹理坐标均为左上原点。compute 写入后以 shader-write → shader-read 依赖衔接显示 pass；后者直接读取这些 GPU 图像并写宿主主图像，不复制整帧、不经 CPU 回读。最终视图用 primeDRT；噪声预览只做工作空间转换、曝光及 sRGB 编码，超范围裁剪；深度预览按设置范围映射灰度，天空黑；法线映射 `0.5*n+0.5`，miss 黑。预览不改变输入纹理值。

这三张纹理建立噪声色和 DLSS RR 深度/法线输入的基础语义，尚未调用 DLSS RR，也不是完整 RR 输入集合：运动矢量、反射/漫反射 albedo、specular hit distance、重建资源标记及设备集成仍待实现。现阶段不暴露未实现的降噪器开关。

## 离线累积

离线用共享的传输算法，只分配 float4 线性均值 buffer，CPU 持有样本计数并通过 push constants 传入。每帧追加配置数量的独立样本，使用递增样本索引；批量执行与逐帧执行数学等价。不重投影、不做时间滤波、不混入实时历史。primeDRT 在均值之后执行，显示参数和每帧样本数变化不清空历史。尺寸变化或重新进入离线会清空；达到 `2^24` 样本前重启，避免 f32 计数失去单位精度。Z-Sobol 分组和当前物理近似见 [shader 契约](shaders.md)。

独立 `prime_render` 和 GPU 测试可以显式读回输出进行断言；生产模式切换、呈现和诊断不使用该路径。离屏与 CPU Mixin 验证不能代替对应版本的窗口、快捷键和菜单实机验收。
