# 轻量路径记录复用分析

2026-09-05。基于已运行正常的摄像机大气近似与窄 any-hit 版本，分析轻量渲染器的下一步布局。
本轮接入 RR 与 subgroup 队列追加，**实际路径 stride 仍为 128 B**；下列 96/80/64 B 是可审查的
布局候选，尚未落地或测量。更完整的材质模型需要重新审查同时存活的字段。

后续去调制 RR 实验已占用 `direction.w / throughput.w / firstDirection.w` 保存首表面 RGB
反照率，128 B stride 不变。下列候选是此前的布局分析，尚未计入这 12 B 持久数据；迁移前必须
重新安排这些槽位或明确复用已有 guide 图像，不能直接沿用原始必需字节数。

## 结论与优先次序

用一个 u32 control 标记互斥阶段是可行的。建议先明确阶段读写合同，再用固定大小的存储块
提供各阶段专用窄访问器，保留一像素一记录和现有两条索引队列。无需变长编码、动态路径池、
自由链表或额外 GPU 提交。固定 stride 可以随功能版本变化，不必提前给所有未来状态留空间。

优先考虑 80 B 的 Lambert 布局：保留全部 f32 精度和精确身份，首散射方向直接写已有重建通道。
如果先不改变图像写入时机，96 B 是更小的一步。64 B 还需要利用纯 Lambert 权重消去 albedo；
它是基线模型的特化，不能据此承诺完整 PBR 也只需 64 B。

## 生命周期决定能否重叠

| 当前字段 | 必须存活的范围 | 可采取的操作 |
| --- | --- | --- |
| origin.xyz | trace 前的源点；hit 后成为权威表面点 | 两者已经复用；保留 f32 |
| direction.xyz | trace 输入；miss 时用于环境方向 | Lambert hit 后不再需要入射方向，可与 normal 复用 |
| normalDistance.xyz | hit 后至当前 shade 结束 | 与 Lambert 射线方向互斥；PBR 通常不满足这一条件 |
| normalDistance.w | trace 写 guide、保存首次次级距离、通知 shade 是否 miss | 前两次消费可在 trace 内完成；持久记录仅需 control 的 Hit/Escaped 标志 |
| throughput.rgb | 活跃路径始终需要；当前 NEE 和后续散射都消费 | 通用模型的持久核心，不能与 radiance 或任意材质权重重叠 |
| albedo.rgb | 当前 hit 至 NEE/散射完成 | Surface 阶段私有；只有纯 Lambert 可提前折入 throughput |
| identity.xy | 源 section/triangle；hit 后变成当前表面身份 | 已经复用；保留两个完整 u32，阴影与延续追踪均需读取 |
| identity.z / w | 已完成散射数 / 首表面是否命中 | 与阶段标记合并为一个 u32 control |
| radiance.rgb / w | 累计间接光 / 第一次散射后的距离，直到 resolve | 终止也不能丢弃；distance 仍为 f32 |
| firstDirection.xyz | 第一次散射至 resolve，仅供 SH 输出 | 可在产生时写已有 diffuseDirection 图像，不必留在路径记录 |
| direction.w / throughput.w / firstDirection.w | 首次 shade 至路径终止，保存固定首表面 RGB 反照率 | 去调制 RR 已使用；不能与当前表面 albedo 重叠 |
| 其余未用 w | 无实际消费者 | 用于明确的整数/连续字段，不通过浮点数值承载身份 |

可采用四个阶段：`TraceReady → SurfaceReady 或 Escaped → TraceReady 或 Finished`。
`Escaped` 累加环境后进入 `Finished`。阶段占 2 位，散射数 0–12 占 4 位，首表面命中占 1 位；
保留位保持未分配。未来引入新阶段时再扩展编码，不能把“现在没用到”当成隐含状态。

control 是记录有效性的描述，不是必须让所有 entry 都跑一遍的大 switch。trace/shade/resolve
仍是静态分开的 entry，只加载所需字段；队列决定调度，control 决定该阶段记录的解释方式。
单一路径所有者与已有 dispatch 间 barrier 负责发布，不需对 control 做原子操作。

**显存别名不自动减少寄存器。** 避免先解包整个大记录，再根据 tag 选择只用其中一部分；
也避免用包含全部材质/介质状态的通用返回结构。材质、RR 随机数与下一方向应在阴影 trace 后
读取或计算。阶段访问器必须在源码闭包和生成产物中都保持窄加载，不能依赖 slangc 消除死字段。

## 固定大小候选布局

下表按 16 B 行表达物理布局。`float3 + uint` 是各自类型明确的字段；若采用 uint4 原始存储，
浮点只做位重解释，不能把身份数值转换为 float。所有世界位置、方向、法线仍为 f32。

| 16 B 行 | 96 B 候选 | 80 B 候选 |
| --- | --- | --- |
| 0 | position.xyz + control | 相同 |
| 1 | Trace/Escaped: direction；Surface: normal；另存 section | 相同 |
| 2 | throughput.rgb + triangle | 相同 |
| 3 | Surface: albedo.rgb + 保留 | 相同 |
| 4 | radiance.rgb + firstSecondaryDistance | 相同 |
| 5 | firstDirection.xyz + 保留 | 已写入现有 SH 方向通道，无此行 |

96 B 布局的原始必需数据为 88 B，80 B 布局为 76 B。为节省最后 8/4 B 改用非 16 B stride 的
原始字节地址布局，需要额外核对跨记录访问、访存合并和地址计算；目前优先保持固定行的简单实现。

80 B 要同步修改三个位置：primary guide 在启用 SH 时清零 diffuseDirection；首散射生成时写入；
resolve 不再覆盖它。保持现有可选输出条件，防止未启用后端的 alias descriptor 被错误写入。
首次 RR 终止时保留零方向、零间接光和未产生次级命中的距离约定；最终重建前已有图像依赖。
此调整不增加纹理，不把方向读回路径，也不增加 dispatch。图像量化只是提前发生在同一个输出边界。

64 B 特化可再去掉 albedo 行：trace 先用 albedo 写首表面 guide，然后更新 `β *= albedo`。
shade 的 Lambert NEE 消费这一乘积，延续权重也正是这一乘积；主表面太阳写入仍按 β=1 的合同。
RR 在 NEE 后只补偿后续 β。这个代数化简需要重新验证当前光照顺序、零反照率和所有重建通道，
不能只删字段后希望优化器修复依赖。

## 对显存与流量的影响

只计算路径记录和两个 u32 像素索引队列；另有 32 B 命令与最多 255 B 对齐，不含场景、图像、
驱动 RT 栈和重建历史。以下 MiB = 2²⁰ B。

| 路径 stride | 2560×1440 总量 | 3840×2160 总量 | 4K 相对当前节省 |
| --- | ---: | ---: | ---: |
| 当前 128 B | 478.125 MiB | 1075.781 MiB | — |
| 96 B | 365.625 MiB | 822.656 MiB | 253.125 MiB |
| 80 B | 309.375 MiB | 696.094 MiB | 379.688 MiB |
| 64 B，纯 Lambert 特化 | 253.125 MiB | 569.531 MiB | 506.250 MiB |

不能把 stride 缩小的比例直接当成逐反弹带宽下降比例：当前 shader 已经按阶段加载部分成员，
缓存与事务大小也参与成本。96 B 主要消除 padding/冗余持久字段并缩小工作集；80 B 避免路径中
存放/resolve 读取 firstDirection；64 B 才进一步消除持久 albedo 的写入和读取。

RR 降低活跃路径数、后续 trace 数和队列流量；subgroup 降低追加原子竞争。两者都不降低固定
N 像素记录/队列的分配容量，也不改变现有 28 个 dispatch 的命令数量。为了回收 RR 空位增加
动态槽位分配器，会引入身份映射和重建输出所有权，不是当前优先项。

## 恢复 PBR 时的约束

1. **入射方向与 normal 可能同时存活。** BSDF evaluate/sample 需要 wo 与表面法线，不能继续
   把两者无条件重叠；也不能从已被命中点覆盖的 origin 重建 wo。若仅恢复这一项，80 B 候选
   就可能回到约 96 B；具体取决于新增材质信息的同时存活集合。
2. **媒质、eta 补偿、前次 MIS 状态可能跨越阶段。** 它们是持久字段，即使只被某个阶段读取。
   delta 窄 megakernel 内部临时量可留在 kernel 内；一旦需要交给 wavefront 就必须显式保存。
3. **阴影不一定与散射互斥。** 当前 TraceRay 阴影在 shade 内同步完成。未来若独立排队，待累加
   的 direct 权重、源/目标身份与仍需执行的 continuation 可能同时存在，不能全部映射到一份
   scratch 后让阴影和散射并行读取。应明确阶段顺序或另存很小的 shadow work item。
4. **终止不等于记录无用。** 累计光照、首表面标记及重建距离直到 resolve 仍有消费者。阶段
   scratch 可以死亡，核心信号必须保留。单分支基线不必引入跨路径原子累加。

因此推荐复用的是“持久核心 + 按确切生命周期互斥的阶段区”的架构。每恢复一个材质能力，先
画出数据产生/最后消费的位置，再确定布局；不要把当前 Lambert 的最小字节数当成通用约束。

## 本轮已接入的 RR 与 subgroup

2026-09-06 后续实测选择线性 RR 作为实时与离线固定策略，四档调试及备用实现已删除。
下文记录历史接入与去调制实验过程，当前策略及透明单光照存储见[实现记录](透明单光照分支实验.md)。

最初 RR 复用旧 `sqrt(max(β) * etaScale)`；后续实验改为 `sqrt(maxRGB(β / firstAlbedo))`，
上界 1 与 `β /= p` 规则保持。Lambert 的 etaScale 固定为 1，firstAlbedo 在路径生命周期内固定。
从第一次散射开始，当前顶点阳光贡献先结算，随后 RR 决定是否发布后继。没有人为 0.95 上限。
零 throughput 在除法前终止。12 次散射的截断仍保留，因此 RR 保持的是**既定截断估计器的期望**，
不补回第 13 阶及以后被舍弃的能量。平均路径缩短可能伴随方差增加，需观察实际重建画面。

太阳与散射仍用既有 STBN bank 2/0。RR 使用旧独立 hash effect/stream，按像素、sample index、
epoch、已完成散射数取样；分支固定为 0。哈希核心抽成共享叶模块，避免把 Sobol 表引入 shade。
当前重新计算 seed，不给路径记录增加字段；如后续捕获显示哈希成本显著，再比较一次计算并保存
u32 seed 的带宽/生命周期代价。

subgroup 只改变单后继索引追加：ballot 统计存活数，选中 lane 预留连续区间，broadcast + prefix
为每个存活路径分配唯一 slot。全终止组不做全局原子；不硬编码 32 lanes。退出逻辑集中到返回
continuation 的 shade helper，所有调用者再到达共同追加点。不会把 ballot 或 lane 身份带过 trace。
能力检查沿用 raygen stage 的 BASIC + BALLOT 支持；不依赖 SER，支持时选独立 subgroup artifact，
否则用标量 artifact。没有扩大其他 Lambert entry 的 subgroup 编译闭包。

GPU 行为验证覆盖 RR 存活边界、零/单位概率、低权重有限性、12 阶解析积分与旧哈希映射，以及
两种队列追加在空/全存活/混合/稀疏/尾部不足一组、两种队列 parity 下的计数和唯一性。
真实寄存器与帧时间的增量记录在[寄存器记录](轻量渲染器寄存器记录.md)，以新捕获为准。
